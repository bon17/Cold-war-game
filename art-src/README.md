# art-src: 그림 원본

ChatGPT로 만든 그림 원본을 둔다. 규칙은 `docs/art-direction.md` 7장을 따른다.

- `<이름>_vNN.*`: ChatGPT가 만든 그대로의 원본(시도 번호).
- `<이름>.png`: 고른 그림. 아래 보정을 거친 판이고, 빌드 스크립트는 이 파일을 쓴다.

## 보정 기록

| 파일 | 원본 | 보정 |
|---|---|---|
| `_ref/anchor-desk.png` | `_ref/anchor-desk_v01.webp` | 밝기만 올림(감마 0.62, 평균 밝기 68 → 105). 그림 내용은 그대로. 이후 모든 요청에 이 파일을 첨부한다. |
| `rooms/room-1970s.png` | `rooms/room-1970s_v02.webp` | 그림 전체를 오른쪽으로 80px 옮김. 텔레비전이 보드(x 215~1160)에 가려지지 않게 하려고. 왼쪽 빈 곳은 원본 왼쪽 160px를 240px로 늘려 채움. 전화기 오른쪽 끝이 조금 잘림. |

| `shared/clock-bezel.png` | `shared/clock-bezel_v01.webp` | 보정 없음(형식만 PNG로). 정원(가로세로 차이 0.5%), 판에 눈금·숫자 없음, 실제 투명. 판이 전체 지름의 약 73%라 `layout.json`의 `faceR`을 116 → 108로 바꿈. |
| `shared/board.png` | `shared/board_v01.webp` | 그린 비율이 1.67:1이라 세로를 약 11% 늘려 정확히 3:2(1454×969)로 맞춤. 둘레에 투명 여백 20px. 코르크가 사진처럼 매끈하지만 게임에서는 차트 종이가 덮고 가장자리 띠만 조금 보여서 그대로 씀. |
| `shared/lamp.png` | `shared/lamp_v01.webp` | 보정 없음. 기준 그림의 램프와 같은 디자인, 불빛 없음, 실제 투명. 가로가 더 긴 모양(1.08:1)이라 `layout.json`의 램프를 259×240으로 바꿈. |
| `shared/frame-wood.png` | `shared/frame-wood_v01.webp` | 보정 없음. 유리 자리 실제 투명, 창살 없음. 틀이 요청보다 두껍고(폭의 14.5%) 비율이 0.71이라 `layout.json`의 창을 188×264, `pane`을 134×209로 바꿈. |

- 공용 그림 4장은 모두 요청(캔버스 높이의 26~30%)보다 두 배쯤 크게 그려졌다. 게임 크기로 줄여 방 그림에 얹어 보니 선 굵기는 방 그림과 어울려서 다시 만들지 않았다.
- `rooms/room-1970s` 첫 시도(v01)는 텔레비전이 보드 자리까지 나와서 버렸고, 파일은 보관하지 않았다.
