# art-src: 그림 원본

ChatGPT로 만든 그림 원본을 둔다. 규칙은 `docs/art-direction.md` 7장을 따른다.

- `<이름>_vNN.*`: ChatGPT가 만든 그대로의 원본(시도 번호).
- `<이름>.png`: 고른 그림. 아래 보정을 거친 판이고, 빌드 스크립트는 이 파일을 쓴다.

- 2026-10-20 교사가 깃허브에 원본 PNG를 올려서, 채팅으로 받아 webp로 보관했던 원본(`room-1970s_v02`, 공용 그림 4장)을 PNG 원본으로 바꾸고 보정판을 PNG 원본에서 다시 만들었다(보정 방법은 같음).
- **버린 시도:** `rooms/room-1950s_v01.png`(책상 윗선 y 575로 너무 높아 보드가 책상에 걸림, 서랍이 보임, 컵이 보드 자리, 라디오가 명판 자리까지 올라옴. v02로 해결). **다시 그릴 것:** `rooms/room-now_v01.png`(사진이나 3D 렌더처럼 매끈함, 평균 밝기 141). 원본은 기록으로 남긴다. 다시 그릴 프롬프트는 `docs/art-prompts.md` 8.2.

- 공용 그림 4장은 모두 요청(캔버스 높이의 26~30%)보다 두 배쯤 크게 그려졌다. 게임 크기로 줄여 방 그림에 얹어 보니 선 굵기는 방 그림과 어울려서 다시 만들지 않았다.
- `rooms/room-1970s` 첫 시도(v01)는 텔레비전이 보드 자리까지 나와서 버렸고, 파일은 보관하지 않았다.
