> 쓴 날: 2026-10-20. 근거: `docs/art-direction.md` 4.4(좌표), 6장(그림 목록, 창밖 장면, 표지 연작), 7장(작업 가이드), 8.5(종류별 규칙), 8.6(화풍 시험에서 배운 것).

## 0. 쓰는 법

1. 그림마다 **정보표의 '첨부' 그림을 먼저 올리고**, 회색 상자 안의 프롬프트를 **처음부터 끝까지 통째로** 복사해 붙인다. 첨부 그림 파일은 저장소의 `art-src/` 폴더에 있다.
2. 순서는 이 문서의 순서(7.2 작업 순서)를 따른다. 확정된 그림이 다음 그림의 첨부가 되므로 순서를 건너뛰지 않는다.
3. 대화는 종류별로 나눈다: '공용 소품', '창밖', '표지', '방', '질감'(7.4). 한 대화에서 10번 넘게 만들었거나 화풍이 흐려지면 새 대화를 열고 첨부부터 다시 한다.
4. 고칠 때는 `art-direction.md` 7.7의 문구를 쓴다. 이 그림에서 자주 생길 문제의 문구는 그림마다 '고칠 때' 칸에 더 적었다. **한 번에 한 가지만, 편집은 두 번까지**(7.3).
5. 받은 그림은 **Claude가 답을 마친 뒤에** 보여 준다(8.6 8번). 한 회차의 그림(3장 안팎)은 한 메시지에 함께 보내도 된다(2026-10-20 공용 그림 4장을 한 번에 받아 문제없이 저장함). 저장과 파일 이름은 Claude가 한다.
6. 색이 조금 다르거나 위치가 몇십 픽셀 어긋난 정도로는 다시 만들지 않는다. 색은 빌드가, 위치는 Claude가 맞춘다(7.3, 8.6 4번).

### 0.2 Claude가 숫자로 검수하는 기준

교사는 그림을 보여 주기만 하면 된다. Claude가 아래를 재서 알려 주고, 필요하면 밝기나 위치를 보정한다(8.6 7번).

| 종류 | 확인하는 것 | 통과 기준 |
|---|---|---|
| 불투명 그림(종이 결 제외) | 평균 밝기(0~255) | 약 105(95~120). 기준 그림 105, 1970년대 방 109. 낮 그림(지금의 방, 에필로그 표지)은 125까지 |
| 불투명 그림(종이 결 제외) | 아주 어두운 곳(밝기 40 미만)의 비율 | 5% 이하. 기준 그림 0.6%, 1970년대 방 3.5% |
| 종이 결 | 밝기의 고르기 | 네 구석과 가운데의 평균 밝기 차이 10% 이내 |
| 투명 그림 | 네 모서리와 물건 바깥의 알파 | 0(완전 투명). 회색·흰색 바둑판 무늬가 아님 |
| 투명 그림 | 물건 테두리의 비율 | 시계 1:1, 보드 3:2, 램프 2:3, 창틀 2:3에서 3% 이내 |
| 투명 그림 | 게임 크기로 줄였을 때 선 굵기 | 방 그림의 잉크 선과 비슷함(4.4 좌표에 얹은 확인 그림으로 비교) |
| 방 그림 | 책상 윗선, 소품 자리 | 책상 윗선 y ≈ 700. 소품 왼쪽 끝 x ≥ 1160(보드 오른쪽 끝), 가장 높은 곳 y ≥ 450 |
| 창밖 그림 | 가운데 세로 띠 | 중요한 사람들이 가운데 40%(x 약 460~1076) 안에 있음 |
| 표지 그림 | 위쪽 30% | y 0~307에 물건이 없음 |

### 0.4 회차 계획 (2026-10-20 교사 요청: 한 번에 3장쯤)

한 회차에 서로 기다릴 필요가 없는 그림 3장을 묶었다. 그림 하나에 프롬프트 하나(한 요청에 한 그림, 7.3)는 그대로다. 교사는 한 회차의 프롬프트 3개를 차례로 넣어 3장을 만들고, 한꺼번에 Claude에게 보여 준다. Claude는 회차마다 프롬프트를 코드 블록으로 따로 정리해 준다.

| 회차 | 그림 | 먼저 확정돼 있어야 하는 것 |
|---|---|---|
| 1 | ⑦ 3장 창밖, ⑧ 3장 표지, ⑨ 종이 결 | 기준 그림(완료) |
| 2 | ⑩ 1950년대 방, ⑪ 1980년대 방, ⑫ 지금의 방 | `room-1970s`(완료) |
| 3 | ⑬ 금속 창틀, ⑭ 프롤로그 창밖, ⑮ 1장 창밖 | `frame-wood`(완료), ⑦ |
| 4 | ⑯ 2장 창밖, ⑰ 4장 창밖, ⑱ 5장 창밖 | ⑦ |
| 5 | ⑲ 에필로그 창밖, ⑳ 프롤로그 표지, ㉑ 1장 표지 | ⑦, ⑧ |
| 6 | ㉒ 2장 표지, ㉓ 4장 표지, ㉔ 5장 표지 | ⑧ |
| 7 | ㉕ 에필로그 표지 (+ 여유 ㉖ 키 아트, ㉗ 에필로그 서울 거리) | ⑦, ⑧ |

- 작은 공용 그림은 ⑬ 금속 창틀만 남았다. 나머지는 모두 화면을 채우는 그림이라 한 장씩 그린다.

- 공용 그림의 두 번째 첨부(8.5 '확정된 다른 공용 그림 1장')는 이미 확정한 공용 그림 가운데 재질이 가장 비슷한 것이다(보드 ← 시계의 나무 테, 램프 ← 시계의 놋쇠 고리, 나무 창틀 ← 보드의 나무 틀, 금속 창틀 ← 나무 창틀의 크기와 틀 폭). 받을 때마다 Claude가 게임 좌표에 얹어 크기와 선 굵기를 확인한다(7.2).

## 1. 공용 그림 (투명 배경, 80년 재사용)

### 1.1 공용 그림의 공통 조건

- 물건 하나만 그린다. 배경은 투명, 바닥 그림자와 주변 빛 번짐은 없다.
- **실제 크기 그리기**(6.1): 1536×1024 캔버스에 물건을 게임 속 크기와 비슷하게 작게 그린다. 줄이는 비율이 1에 가까워서 선 굵기가 방 그림과 저절로 맞는다. 보드만 캔버스의 약 90%를 채운다.
- 빛은 왼쪽 앞에서 약하게, 색은 중성(따뜻한 빛 색을 입히지 않음). 장별 빛 색과 접촉 그림자는 코드가 넣는다(3.2).
- 놋쇠와 나무는 무광(8.6 2번).
- **투명이 안 되면:** 7.7 '투명 배경 실패' 문구로 한 번 더 요청한다. 그래도 안 되면 아래 문구로 자홍색 배경을 받는다. 빌드가 그 색을 지운다(7.5).
  ```
  배경을 투명 대신 아무 무늬 없는 순수한 자홍색(마젠타) 단색으로 다시 만들어 줘. 물건은 그대로, 물건 가장자리에 자홍색이 번지지 않게.
  ```

### 1.2 ③ 시계 테두리 `clock-bezel`

| 항목 | 내용 |
|---|---|
| 번호 | 3 (M2 ③) |
| 파일명 | `art-src/shared/clock-bezel_vNN.png` → 고른 그림 `art-src/shared/clock-bezel.png` → 배포 `public/assets/shared/clock-bezel.webp` |
| 크기 | 1536×1024 캔버스, 시계 지름은 캔버스 높이의 약 30%(약 300픽셀). 게임 속 296×296 |
| 투명 | 예 |
| 첨부 | 기준 그림 `art-src/_ref/anchor-desk.png` |
| 횟수 | 2~4번 생성 → 1장 선택 |
| 대화 | '공용 소품' 대화의 첫 그림 |

```
첨부한 기준 그림과 같은 화풍(잉크 선의 굵기와 색, 과슈 붓 자국, 종이 결, 색의 수)과 같은 밝기로 게임에 쓸 물건 그림 하나를 그려 줘. 가로형 1536×1024 캔버스. 배경은 투명(알파 채널 PNG).

용도: 게임 화면의 벽에 걸리는 둥근 벽시계의 '테두리'다. 시계 판의 눈금, 숫자, 바늘은 게임이 나중에 따로 그려서 이 그림의 판 위에 덮는다. 그래서 판은 아무것도 없이 비워 둔다.

물건: 오래된 둥근 벽시계 하나. 사람은 없다.
- 바깥 테: 짙은 호두나무로 만든 둥근 나무 테. 오래 써서 윤기가 죽은 무광이다. 나뭇결이 은은하게 보인다.
- 안쪽 테: 나무 테 안쪽에 가는 바랜 놋쇠 고리 하나. 바랜 무광 놋쇠이고 강한 반사광은 없다.
- 시계 판: 놋쇠 고리 안쪽은 무늬 없는 크림색 원판이다. 판의 지름은 시계 전체 지름의 약 5분의 4다. 판에는 눈금, 숫자, 바늘, 가운데 축, 로고, 글자를 하나도 그리지 않는다. 유리 반사나 빛 무늬도 없다.
- 걸이 고리, 끈, 못, 추, 장식은 없다. 둥근 테만 있다.

시점과 구도(가장 중요):
- 시계를 정면에서 똑바로 본다. 찌그러지지 않은 완전한 정원이다. 비스듬한 각도나 두께가 보이는 옆면은 없다.
- 캔버스 가운데에 시계 하나만 작게 그린다. 시계의 지름은 캔버스 높이의 약 30%(약 300픽셀)다.
- 외곽선의 굵기는 첨부한 기준 그림의 선 굵기와 같게 한다. 크기가 작으니 세부는 단순하게.
- 시계 바깥의 모든 픽셀은 완전히 투명하다. 바닥 그림자, 벽, 배경색, 바둑판 무늬는 없다. 종이 결도 시계 안에만 넣는다.

빛: 왼쪽 앞에서 약한 빛이 든다. 빛의 색은 따뜻하지도 차갑지도 않은 중성이다. 테의 오른쪽 아래가 조금 어두운 정도로만 입체감을 준다. 테 주변에 빛 번짐이나 그림자는 없다.

색: 짙은 호두나무 갈색, 바랜 놋쇠색, 크림색 판.

손으로 그린 2D 그래픽 노블 일러스트. 잘 만든 인디 내러티브 게임의 배경 아트처럼.
선: 가늘고 살짝 흔들리는 짙은 갈색(세피아) 잉크 외곽선. 새까만 외곽선은 쓰지 않는다. 해칭은 그림자 속에만 조금.
```

## 2. 3장 장면 그림 (M2)

### 2.1 창밖 장면의 공통 조건

- 프롤로그~5장의 창밖은 **같은 거리를 같은 카메라로** 본 80년이다(2.5, 6.3). 그래서 모든 창밖 프롬프트(에필로그 휴전선 제외)에 아래 **고정 시점 문단**을 한 글자도 바꾸지 않고 넣는다. 바뀌는 것은 연도, 계절, 시간, 건물 높이, 사람들뿐이다.

  > 시점(가장 중요): 길 건너편 건물 2층 높이에서 비스듬히 내려다본 먼 시점. 카메라는 고정되어 있고 수평이다. 화면 아래쪽 약 3분의 1은 화면을 왼쪽에서 오른쪽으로 가로지르는 길과 건너편 인도다. 그 위로 건너편 건물들의 앞면이 화면 가로 전체에 나란히 늘어선다. 하늘은 화면 맨 위 약 5분의 1에만 조금 보인다. 사람들은 모두 작게 보이는 먼 거리다.

- 게임은 이 그림을 전체 화면으로도 쓰고, 창 안(가운데 세로 띠)에서도 쓴다. 그래서 **중요한 사람들은 화면 가운데 세로 띠(가로의 약 40%) 안에** 모은다. 창 안에서는 작게 보이므로 크고 단순한 모양이 좋다.
- 사람은 작게, 뒷모습과 옆모습으로, 얼굴의 눈코입 없이. 손은 짐, 신문, 주머니, 소매로 가린다.
- 간판, 신문, 화면은 글자 없는 색면이나 흐린 붓 자국. 국기와 깃발은 멀리 작게도 그리지 않는다.
- 창밖은 실내 조명 규칙 대신 그 장면의 자연광으로 그린다. 그래도 화면 전체는 중간 밝기다. 밤 장면도 어둠은 코드가 넣는다(8.6 1번).
- 옷차림, 건물, 탈것은 모두 `TODO(교사 확인)`이다(10.2 8~14번). 확신이 없는 것(전차, 간판 모양, 버스)은 그리지 않는다.
