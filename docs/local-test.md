# 내 컴퓨터에서 체험판 열어 보기 (교사용)

> 2026-10-22 결정: 개발 중에는 교사가 자기 컴퓨터의 로컬 서버로 확인하고, 인터넷 배포는 마지막에 한 번만 한다.
> '로컬 서버'는 내 컴퓨터 안에서만 열리는 게임 주소(`http://localhost:5173`)다. 다른 사람은 들어올 수 없다.

---

## 0. 가장 쉬운 방법: 비공개 링크 (2026-10-23)

설치할 것이 없다. 아래 링크를 누르기만 하면 된다.

- 체험판 링크: https://claude.ai/artifact/XuA4oj5YFn1HKLfaANBuqu (2026-10-23 새 링크. 2026-10-25 프롤로그, 1장, 3장, 7판: 1장에 1948년 문서)
  - 예전 링크(https://claude.ai/artifact/YZrqj4SFsHZr3k4iy3e7TK)는 다음 세션에서 열 수 없어 고칠 수 없었다. 이제 새 링크만 쓴다.
- **비공개**다. 교사의 claude.ai 계정으로 로그인한 상태에서만 열린다. 학생이나 다른 사람은 열 수 없다(인터넷 공개 배포가 아니다).
- 진행 저장은 그 링크를 연 브라우저에만 남는다. 다른 컴퓨터에서 열면 처음부터 한다.
- 링크 화면 안에서는 '전체 화면' 단추가 안 될 수 있다. 그때는 브라우저 창을 크게 키운다.
- Claude가 게임을 고치면 같은 링크를 새 판으로 바꿔 둔다. 링크 화면에서 새로 고침만 하면 된다.

아래 1~4장의 로컬 서버 방법은 링크가 안 열릴 때나, 인터넷이 없는 곳에서 쓸 때만 쓴다.

## 1. 처음 한 번만 준비

### 1.1 Node.js 설치

1. https://nodejs.org 에 들어가 **LTS**라고 적힌 판을 내려받는다(22 이상).
2. 내려받은 파일을 열고 '다음'만 눌러 설치한다. 설정은 바꾸지 않는다.

### 1.2 GitHub Desktop으로 저장소 받기

1. https://desktop.github.com 에서 GitHub Desktop을 설치하고, 깃허브 계정으로 로그인한다.
2. **File → Clone repository** → 목록에서 `bon17/Cold-war-game`을 고르고 **Clone**을 누른다. 저장할 폴더는 기본값 그대로 둔다.
3. 위쪽 **Current branch**를 눌러 **`claude/inspiring-euler-r60svo`**를 고른다(2026-10-23부터. 프롤로그가 들어간 가지).
   - 저장소의 기본 가지(`claude/determined-galileo-7vzo49`)에는 아직 게임 코드가 없다. 꼭 이 가지로 바꾼다.

---

## 2. 체험판 열기 (매번)

1. GitHub Desktop에서 **Repository → Show in Explorer**(맥은 **Show in Finder**)를 눌러 저장소 폴더를 연다.
2. 윈도는 **`start-windows.bat`**, 맥은 **`start-mac.command`**를 두 번 클릭한다.
3. 검은 창이 뜨고 세 단계가 지나간다.
   - [1/3] 필요한 프로그램 확인: 처음에는 1~3분, 그다음부터는 몇 초.
   - [2/3] 그림 준비: 약 10초.
   - [3/3] 브라우저가 저절로 열리며 체험판이 뜬다. 열리지 않으면 크롬 주소창에 `http://localhost:5173`을 친다.
4. 체험판 첫 화면에서 **소리 켜기/끄기 → 램프를 켜세요 → 이름**을 넣고 '처음부터'를 누른다. 막 시작 코드 칸에 '핑퐁외교'를 넣어도 3장이 시작된다.
   - 같은 이름으로 다시 들어오면 '이어하기'로 이어서 할 수 있다. 처음부터 다시 보고 싶으면 다른 이름을 쓰거나 '처음부터'를 눌러 두 번 확인한다.
5. 다 보면 **검은 창을 닫는다.** 창을 닫으면 체험판 주소도 닫힌다.

- 윈도에서 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누른다.
- 맥에서 "확인되지 않은 개발자" 창이 뜨면 파일을 **오른쪽 클릭 → 열기**로 연다.

---

## 3. Claude가 새로 올린 것을 받기

Claude가 "올렸습니다"라고 하면:

1. GitHub Desktop에서 **Fetch origin**을 누른다. 버튼이 **Pull origin**으로 바뀌면 한 번 더 누른다.
2. 2장처럼 실행 파일을 두 번 클릭한다. 새 프로그램과 새 그림은 실행 파일이 알아서 준비한다.

---

## 4. 문제가 생기면

- 검은 창에 빨간 글자나 "문제가 생겼습니다"가 나오면, 그 창을 화면 캡처해서 Claude에게 보여 준다.
- 화면이 이상하면 브라우저에서 **Ctrl+Shift+R**(맥은 **Cmd+Shift+R**)로 새로 고친다.
- `http://localhost:5173`이 안 열리면 검은 창이 아직 열려 있는지 본다. 닫혀 있으면 2장부터 다시 한다.

---

## 5. 개발자용 메모

- 실행 파일이 하는 일: `npm install` → `npm run assets` → `npm run dev -- --open`.
- 비공개 링크 갱신: `npm run assets` → `npm run build:link`(결과는 `dist-link/`, 글꼴 파일 대신 구글 폰트를 씀). `build:link`가 끝에 `scripts/link-page.mjs`를 돌려 링크용 페이지 `dist-link/link-page.html`과 올릴 파일 목록 `dist-link/link-files.json`(코드 2개 + 그림 전부, 약 4MB)을 만든다. 그 페이지를 위 링크(`url`)로 다시 게시하고 `files`에 목록을 넣는다. 바뀐 `static/` 파일은 새 이름으로 올라가므로 옛 이름은 지운다(`null`). 다른 세션에서 고칠 때는 먼저 링크를 읽고(read) 게시한다.
- 학교의 가장 느린 크롬북 시험(아트 계획서 5.6)은 크롬북에서 로컬 서버를 열기 어려우므로 마지막 배포 때 한다.
