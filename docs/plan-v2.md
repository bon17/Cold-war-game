## 1. 개요

| 항목 | 내용 |
|---|---|
| 이름 | **바늘과 실: 자정의 분석실** |
| 한 줄 소개 | 1945년 서울, 신문사 꼭대기 층 분석실의 당직자가 되어 문서를 읽고 나라 사이에 실을 걸고, 과학자들이 발표하는 운명의 날 시계의 바늘이 자정에 가까워질지 판단하는 추론 게임 |
| 이름의 뜻 | "바늘 가는 데 실 간다." 시곗바늘(결과)과 관계의 실(원인)은 늘 함께 움직인다. |
| 대상 | 중학교 2학년. 역사와 읽기를 어려워하는 학생이 다수 |
| 수업 | **2차시**(45분 × 2). 1차시: 프롤로그~2장, 2차시: 3장~에필로그 + 쓰기 |
| 플랫폼 | 웹 브라우저(학교 PC의 크롬·웨일, 크롬북, 가로 모드 태블릿). 서버 없음 |
| 장르 | 데스크 시뮬레이션 + 추론 퍼즐 |

### 1.1 학습 목표

1. 냉전의 형성부터 해체까지를 '갈라짐 → 뜨거워짐 → 다른 길 → 녹음 → 다시 얼어붙음 → 무너짐'이라는 하나의 흐름으로 설명할 수 있다.
2. 냉전을 개별 사건의 나열이 아니라 **나라 사이 관계의 변화**로 이해한다.
3. 사건(원인)이 관계를 바꾸고, 관계의 변화가 세계의 위험도(결과)를 움직인다는 인과 관계를 추론할 수 있다.
4. 세계의 냉전이 끝난 뒤에도 한반도에는 분단이 남아 있다는 점에서 탈냉전의 의미와 한계를 생각해 본다.

### 1.2 이전 게임에서 얻은 교훈 (「라비의 트렁크」)

같은 학생들이 2시간 동안 보통 전체의 약 60%까지 진행했다. 학생들이 막힌 곳은 네 가지였고, 이 게임은 각각에 대책을 둔다.

| 막힌 곳 | 이 게임의 대책 |
|---|---|
| 글이 너무 많음 | 문서는 2~4문장, 약 120자 상한, 새 고유 명사 2개 이하. 대사로 끌고 가는 이야기 없음 |
| 퍼즐이 어려움 | 조작은 세 가지(실 걸기, 칸 놓기, 예측)만 반복. 선택지 3개, 두 번 틀리면 힌트 |
| 뭘 해야 할지 모름 | 프롤로그를 교사 시연으로 함께. 누를 수 있는 물건에 늘 라벨. 단서는 한 번 탭 |
| 역사 내용이 어려움 | 점선 밑줄 낱말 풀이(5.1). 장 표지 질문 한 줄로 그 장의 물음을 먼저 보여 줌 |

## 2. 핵심 콘셉트

### 2.1 실은 원인, 바늘은 결과

- **관계 보드(실):** 나라 핀 사이에 실을 걸어 관계를 표시한다. 문서에서 찾은 단서가 있어야 실을 걸 수 있다.
- **운명의 날 시계(바늘):** 미국 원자 과학자 회보(Bulletin of the Atomic Scientists)가 1947년부터 발표해 온 실제 시계. 학생은 바늘이 자정(핵전쟁)에 가까워졌는지 멀어졌는지 예측한다.
- **연결 고리:** 예측할 때 반드시 관계 보드에서 근거가 된 실 하나를 지목한다. "어떤 관계의 변화가 세계를 더 위험하게, 또는 더 안전하게 만들었는가"를 학생이 스스로 잇게 하는 장치다.

### 2.2 두 개의 눈: 분석관과 과학자

- **분석관(나)의 눈:** 서울에서 나라 사이의 관계를 보고 판단한다. 보고서가 이 판단이다.
- **과학자의 눈:** 세계 밖에서 세계 전체의 위험을 평가한다. 시계가 공개될 때 원자 과학자 회보의 발표 전보가 도착하고, 과학자들이 든 이유가 짧게 나온다. 전보 모양은 게임의 연출이고, 내용은 회보 발표의 사실만 쓴다(교사 확인).
- 예측이 맞으면 '예측 적중', 틀리면 '예측 빗나감' 도장과 "내 예측 → 실제" 결과 줄(2026-10-25, 5.4). 학생은 매번 두 눈을 비교한다.

### 2.3 고정된 시점과 세계관 (자세한 내용: 아트 디렉션 계획서 2장)

- 플레이어는 처음부터 끝까지 같은 방, 같은 책상에 앉는다. 방은 가상의 민간 신문사 **「본샘일보」** 꼭대기 층의 '국제 정세 분석실'이다.
- 이 방의 책상 이름은 **'7번 자리'**다. 장마다 다른 시대의 당직자가 앉고, 학생은 언제나 '이번 당직자'다. 당직자의 얼굴과 손은 나오지 않는다.
- 코르크 보드, 벽시계, 책상, 놋쇠 램프는 80년 동안 그대로다. 벽, 창틀, 시대 소품, 문서 양식만 바뀐다.
- 창은 **"그해 한반도의 한 장면"**을 보여 준다. 배우는 대상은 창밖의 세계지만, 창은 한반도를 비춘다. 이야기 요소는 창밖 장면과 짧은 인계 메모에만 담고, 플레이의 중심은 읽기, 잇기, 판단하기다.
- 분석실, 본샘일보, 당직자는 허구다. 사건, 연도, 시계 값은 실제 기록이다. 이 구분을 타이틀, 프롤로그 첫 화면, 크레딧에 밝힌다(13.2).

### 2.4 참고한 작품 (구조와 연출만 참고, 디자인은 따라 하지 않는다)

『Papers, Please』(책상 위 서류와 도장), 『Return of the Obra Dinn』(적은 색, 추론 확정의 순간), 『Pentiment』(종이와 글꼴로 시대 표현), 『Strange Horticulture』(고정된 책상 시점), 『Unpacking』(물건으로 세월 표현), 『Gorogoa』(그림 안으로 들어가는 전환), 『The Case of the Golden Idol』(단어를 모아 끼우는 추론), 『Twilight Struggle』(긴장도를 트랙 하나로). 빌려 오는 것은 아트 디렉션 계획서 1.3.

## 3. 핵심 플레이 루프

한 장은 다음 다섯 단계로 진행된다.

0. **할 일 카드:** 장 표지 다음에 '이번 당직에서 할 일' 카드가 나온다. 벽의 시계와 보드의 실이 무엇인지, 이번 장의 상황(1~2문장), 할 일 세 가지(문서 3개 읽기 → 실 바꾸기 → 시계 예측)를 보여 준다(2026-10-23).
1. **읽기:** 빛나는 문서 더미를 누르면 새 문서가 열린다. 문서는 하나씩 온다. 핵심 구절은 처음부터 형광펜으로 칠해져 있다. '다 읽었어요'를 누른다.
2. **실 바꾸기:** 문서를 닫으면 그 문서와 짝인 실의 바꾸기 창이 저절로 열린다. "○○–○○ 실은 이제 어떻게 됐을까?" 큰 단추 두 개 중 하나를 고른다. 맞으면 실이 바뀌고 한 줄 설명이 나온 뒤 다음 문서가 온다. 이것을 세 번 한다.
3. **보고하기:** 실을 모두 바꾸면 보고서철이 빛난다. 바뀐 실 목록을 보고 "시계는 자정에 가까워졌을까, 멀어졌을까?" 도장 하나를 누르면 바로 낸다.
4. **과학자들의 발표:** 바늘이 실제 기록대로 움직이고, 해설 카드에 원자 과학자 회보의 발표(과학자들이 든 이유)가 나온다. 그 이유와 이어진 실이 있으면 저절로 바뀐다(3장 미국–소련). 내 판단이 본샘일보 1면 헤드라인으로 인쇄된다. 판단이 틀렸으면 정정 보도가 붙는다.
5. **창밖:** 창밖 장면이 그 시대 한반도의 모습으로 바뀐다. 결과 화면(근무 평정표)에 별이 찍히고, 램프 컷 전환으로 다음 장이 열린다.

- 2차시는 느린 학생에게 빠듯하다. 수업 종료 약 10분 전에 교사가 "아직 5장 중인 사람은 코드 '바늘과실'을 입력하세요"라고 안내하면, 그 학생도 에필로그 쓰기 화면으로 가서 쓰고 끝낼 수 있다(5.10).
- 연출은 짧게 자동 진행한다(8.3). 단, 내용을 담은 카드는 건너뛸 수 없다.

### 4.3 쓰기 (종이 활동지)

- 게임은 학생 글을 저장하거나 전송하지 않는다(서버 없음). 학생은 게임 화면을 보며 **종이 활동지**에 쓴다.
- **게임의 쓰기 화면**('다음 당직자에게 남기는 인계 메모', 7.8)
  1. 보드에서 실 하나를 고른다. 고른 실의 이력이 화면에 나온다(예: 남한–북한 "1950 전쟁 → 1953 대립 → 1972 대화 → 1973 대립 → 1991 대화 · 그 뒤의 변화는 이 보드에 없음"). 이력은 장 데이터로 만들므로 막 시작 코드로 들어온 학생도 같은 이력을 본다(5.2).
  2. 문장 틀을 보여 준다. 예: "세계의 냉전은 1991년에 끝났지만 한반도의 분단은 아직 남아 있다. 그 까닭은 ______ 때문이라고 생각한다. 다음 당직자는 ______을/를 지켜보면 좋겠다." `TODO(교사 작성)`
  3. 단어 상자: 그 장까지 모든 핵심 문서의 단서를 보여 주고, 학생이 직접 모은 단서는 강조한다(코드로 들어온 학생도 비지 않는다).
- **활동지**(M5에서 제작): 이름, 고른 실, 실 이력 칸, 문장 틀, 2~3문장 쓰는 칸. 정답과 채점 기준은 게임에 없고 교사가 정한다. 에필로그 질문은 특정 입장을 유도하지 않는다.

## 5. 시스템 상세

### 5.0 쉬운 흐름 (2026-10-23 교사 결정, 이 장의 다른 항목보다 우선)

교사가 체험판을 해 보고 "뭘 하라는 건지 몰랐고, 내용이 아이들에게 너무 어렵고 복잡하다"고 했다. 그래서 **한 장에 이야기 하나**로 줄인다. 아래와 다른 옛 설명이 이 문서에 남아 있으면 이 절을 따른다.

| | 줄이기 전 | 지금 |
|---|---|---|
| 문서 | 장마다 5~7개(핵심 + 더 읽기), 한 개에 약 120자 | **3개**, 한 개에 2~3문장·100자 이하, 쉬운 말(해요체) |
| 실 바꾸기 | 6단계(문서 열기 → 구절 누르기 → 닫기 → 이름표 → 쪽지 → 관계 3개) | **2단계**: 문서 읽기 → 관계 고르기(2개). 질문은 "미국–소련, 이제 어떤 사이가 됐을까?" + "고른 사이가 보드에 실로 걸려요"(2026-10-23: 실 = 두 나라 사이가 드러나게). 맞히면 같은 창에 '맞아요!'와 한 줄 설명, **'다음 문서 보기'**(다음 문서가 없으면 '확인') |
| 단서 쪽지 | 구절을 눌러 모음 | **없앰.** 문서 하나가 곧 실 하나의 근거. 핵심 구절은 처음부터 형광펜 |
| 시계 | 장마다 1~2번 | **1번** |
| 시계 공개 | 전보 → 바늘 → 해설 → 1면 → 정정 → 보너스 | **바늘 → 해설 카드(과학자 발표 포함) → 1면(정정 보도 포함)** |
| 장 시작 | 인계 메모 퀴즈(3장) | **할 일 카드**(장마다). 순서: 이 장의 상황(누구·언제) → 이 방에서 알아 둘 것 → 할 일(2026-10-23 교사 의견). 프롤로그는 제목 '분석실의 첫날'과 당직 설명 |
| 안내 | '지금 할 일' 한 줄 | '지금 할 일' 한 줄 쪽지 + **진행 막대**(문서 ●●○, 시계 ○) + 다음에 누를 곳이 **빛나고 '여기를 누르세요'** |
| 보드 | 모든 실이 같은 진하기 | 이번 장에서 바뀌지 않는 실은 흐리게 |
| 보너스 질문, 더 읽기, 도움받아 걸림 | 있음 | **없앰** |

- 문서는 하나씩 온다. 앞 문서와 짝인 실을 바꿔야 다음 문서가 온다(실이 없는 문서는 읽으면 다음이 온다).
- 틀리면 실이 흔들리고, 창 안에 "다시 생각해 볼까요? 문서에 이렇게 적혀 있어요. “핵심 구절”"이 나온다. 틀린 선택지는 지워져서 다음에는 맞힌다. 학생이 멈추는 일은 없다.
- 문서 글을 줄이며 빠진 사건(3장: 베트남 전쟁, 중국 핵실험, 닉슨 독트린, 남북 적십자 회담, 미소 전략 무기 제한 협정 문서)은 교사가 수업에서 다룬다. 시계의 실제 이유(3장: 미소 전략 무기 제한 협정)는 해설 카드에서 한 줄로 알려 주고, 그 실(미국–소련)은 그때 저절로 바뀐다(`mode: 'reveal'`).
- 다른 장(프롤로그, 1·2·4·5장, 에필로그)도 같은 규칙으로 만든다. 7.4의 그 장 표는 줄이기 전 설계이고, M3에서 장마다 교사와 문서 3개를 고른다. 2장 중립 구역도 이 규칙에 맞게 다시 정한다.
- **실 없는 문서(2026-10-25):** 실을 바꾸는 문서는 장마다 3~5개로 두고, 실이 없는 문서(사건 배경, 시계 이유)는 읽고 넘어간다('다 읽었어요'를 누르면 다음 문서). 1장은 문서 7개(실 5개 + 원자 폭탄·수소 폭탄). 처음에는 6개(실 4개)였는데, 1장 시작에 '왜 남한과 북한이 대립이지?'가 설명 없이 걸려 있다는 교사 의견으로 1948년 정부 수립 문서를 더했다(2026-10-25).
- **장 중간에 바뀌는 보드(2026-10-25):** 문서를 마치면(짝인 실을 맞히면, 실이 없는 문서는 읽으면) 핀 이름(`nodeLabelsUntil`), 보드에서 내려가는 실(`startBoard`의 `untilDoc`), 새로 나타나는 배경 실(`appearAfterDoc`)이 함께 바뀌고, '맞아요!' 창에 '바뀐 핀 이름', '함께 바뀐 실'로 한 줄씩 나온다. 같은 장에서 같은 실을 두 번 바꿀 수 있다(1장 남한–북한: 1948 대립 → 1950 전쟁).
- **예외: 프롤로그는 문서 5개(2026-10-23 교사 결정).** 반 전체가 교사와 같이 하는 연습 장이라 실 고르기 연습(3번)과 실 없는 문서(2개)를 둔다. 빠듯하면 P-5를 뺀다(M6에서 확인). 7.4 프롤로그.

### 5.1 문서와 단서

|---|---|---|
| **직접** (`direct`) | 문서(`doc`)와 짝인 실. 그 문서를 읽고 나면 학생이 관계를 고른다 | 문서 읽기 → 관계 고르기(선택지 2개) |
| **자동** (`auto`) | 그 문서(`doc`)를 열면 한 줄 설명과 함께 저절로 바뀐다(4-1 속보) | 읽기만 하면 됨 |

| **주어짐** | 장 시작 상태(`startBoard`) | 없음 |

**직접 실 조작**
1. 문서를 읽고 '다 읽었어요'를 누르면 **실 바꾸기 창**이 저절로 열린다. 창을 닫았으면 빛나는 실 이름표(점선 테두리, '여기를 누르세요')를 눌러 다시 연다. 문서를 읽기 전의 실은 누를 수 없다.
2. 창에는 "○○–○○ 실은 이제 어떻게 됐을까?", 방금 읽은 문서 제목과 '문서 다시 보기', 관계 단추 두 개(정답 + 장 시작의 관계, 데이터의 `options`, 숫자 키 1~2)가 있다.
3. 판정: 맞으면 실이 바뀌고 '팅' 소리와 한 줄 설명이 '지금 할 일' 쪽지에 나온다. 틀리면 실이 고른 종류로 잠깐 보였다가 흔들리며 돌아가고, 창 안에 문서의 핵심 구절을 다시 보여 준다. 틀린 단추는 지워진다.
- 선택지 순서: 정답 자리를 실마다 돌려 놓는다(그 장의 직접 실 순서대로 ②①②…).
- 균열은 실의 종류가 바뀌면 사라진다. 직통선 매듭은 2장 끝부터 끝까지 남는다.
- 이번 장에서 바뀌지 않는 실(3장: 남한–소련, 남한–중국)은 흐리게 그린다.

**중립 구역 (2장 전용)** — **2026-10-25 교사 결정(게임에 넣음):** 쉬운 흐름에 맞게 실처럼 **한 번만 고른다.** 비동맹 회의 문서(2-5)를 읽으면 고르기 창이 열리고 "인도·인도네시아·이집트·유고슬라비아·가나는 어느 편에 섰을까?"(미국 편이나 소련 편 / 어느 편도 아님)를 고른다. 맞히면 차트 종이 왼쪽 위(`layout.neutralZone`)에 천 띠 칸이 열리고 다섯 나라 이름이 들어간다. 칸 이름은 고르기 전 '어느 편도 아닌 나라', 맞힌 뒤 '제3 세계'(교사 댓글, `zone.solvedTitle`). 고르기 전에 창을 닫으면 빈 칸('?')이 빛나고 누르면 다시 열린다. 별 한 줄로 센다. 데이터는 장의 `zone`. 아래 단서 방식은 줄이기 전 설계로 쓰지 않는다.
- 차트 종이의 빈 모서리에 '어느 편도 아닌 나라' 천 띠가 열린다.
- 인도(`IN`), 인도네시아(`ID`), 이집트(`EG`), 유고슬라비아(`YU`), 가나(`GH`) 핀을 구역에 놓는다. 조작 순서는 직접 실과 같다(단서 누르기 → 나라 핀 누르기 → 핀이 구역 칸으로 들어감). 시도 횟수와 세 번째 실패 때의 자동 배치도 직접 실과 같다.
- 정답 근거: IN·ID·EG·GH는 '평화 10원칙' 또는 '비동맹', YU는 '비동맹'. (다섯 나라 모두 1961년 제1차 비동맹 회의 참가국이다. 인도·인도네시아·이집트와, 독립 전 '골드코스트'였던 가나는 1955년 아시아·아프리카 회의에도 참가했다. 교과서 221쪽 지도.)

### 5.3 보고서

- 장마다 시계 지점이 **하나** 있다(2026-10-23). `show`는 값만 보여 주고(프롤로그처럼 처음 걸릴 때), `predict`는 보고서를 쓴다.
- 보고서: 이번 장에서 바뀐 실 목록(두 나라 + 지금 관계, 과제 순서)을 보여 주고, "{연도}년, 운명의 날 시계는 어떻게 됐을까?" 도장 두 개(▲ 자정에 가까워졌다 / ▼ 자정에서 멀어졌다) 중 하나를 누르면 **바로 낸다.** 근거 실 고르기는 없앴다.
- 보고서는 `unlockAfterDocs` 문서를 모두 열고 `requireEdges`(없으면 그 장의 모든 직접 실)를 마쳐야 열린다. 그 전에 보고서철을 누르면 '지금 할 일' 쪽지가 "아직 남은 문서가 n개 있어요."를 알려 준다.
- 판정은 방향만 본다. 분 단위 숫자는 맞히지 않아도 된다.

### 5.4 과학자들의 발표와 시계

1. **바늘:** 시계 바늘이 `path`의 중간값을 차례로 거쳐 최종값까지 한 칸씩 끊어 움직인다. 중간값마다 연도와 짧은 캡션(15자 안팎)이 단계당 약 2.5초씩 나온다. 넘김 숫자판 '자정까지 N분'이 함께 넘어간다. 예측(`predict`)이었으면 보고서 도장을 누르자마자(0.3초 뒤) 시계 위에 결과 도장이 찍혀 1.7초 머물고, 도장이 사라진 뒤 바늘이 움직인다: 맞으면 초록 '예측 적중'(화음), 빗나가면 붉은 '예측 빗나감'(낮은 소리). (2026-10-25 교사 의견: 틀려도 아무 반응이 없다 → 도장을 넣음 → '누르면 바로 도장, 그다음 시계'로 순서를 바꿈)
2. **해설 카드(건너뛸 수 없음):** 맨 위에 결과 줄('예측 적중!' 초록 / '예측이 빗나갔어요' 붉은색, 그 아래 "내 예측: 가까워졌다 → 실제: 멀어졌다", 빗나갔으면 "왜 그랬을까요? 아래 해설을 읽어 보세요."). 이 결과 줄이 예전의 비교 한 줄("과학자들도 같은 판단을 했어요 / 다르게 봤어요")을 대신한다. 그 아래에서부터 '원자 과학자 회보 발표 · {연도}', '자정까지 N분', "시계가 자정에서 멀어졌어요/가까워졌어요" + 과학자들이 든 이유 1~2문장(사실만, 교사 확인, `clock.json`의 `bulletin.reason`), 그 지점의 해설(`explanation`), 함께 바뀐 실(`reveal` 실). 2026-10-23: 발표 전보를 따로 띄우지 않고 이 카드에 합쳤다. 1947년만은 평가 발표가 아니므로 '처음 실린 표지' 설명으로 대신한다(7.3).
3. **자정 압력:** 시계 값에 따라 비네트, 방 채도, 초침 소리, 시계 둘레의 붉은 빛, 시계 크기가 바뀐다(아트 계획서 3.6). 방의 낮과 밤은 바꾸지 않는다.
- 시계가 처음 걸릴 때와 시계를 누를 때 설명 카드: "이 시계는 실제 시각이 아닙니다. 과학자 단체가 세계가 핵전쟁(자정)에 얼마나 가까운지 평가해 발표하는 상징 시계입니다."
- 시계 디자인은 회보의 상징 디자인을 따라 하지 않는다(평범한 둥근 벽시계).

### 5.5 결과 연출

- **본샘일보 1면:** 보고서를 제출하면 판단이 헤드라인으로 인쇄된다. 템플릿: `[분석실 보고] {연도}년, 세계는 자정에서 {멀어졌다/가까워졌다}`, 그 아래 "바뀐 실: 중국–소련 대립 · 미국–중국 대화 …"(2026-10-23: 근거 실 고르기를 없애며 바꿈). 판단이 틀렸으면 '정정 보도' 상자가 실제 결과를 보여 준다(건너뛸 수 없음). 제호는 1950~80년대 「본샘일보」, 에필로그는 영문 로고 「BONSSAM」 인터넷 신문. `show` 지점에는 1면이 없다. 근거 실이 없는 에필로그는 `[BONSSAM] 지금, 세계는 자정에 {가까워졌다/멀어졌다}` 템플릿을 쓴다.
- **창밖 장면:** 장이 끝나면 창 안에 그 시대 한반도 장면이 떠오르고 화면이 창 안으로 들어간다. 캡션 1~2문장(그 장 문서의 사실 범위). 8초 이내. 'AI 일러스트 · 실제 사진 아님' 표시.
- **장 전환(램프 컷):** 램프가 꺼지고 어둠 속에 실만 남은 뒤, 일력이 넘어가고 새 시대의 방에 불이 켜진다. 처음 3.5초, 두 번째부터 1.5초.

### 5.6 별점과 등급

- **장별 별 3개**(1~5장, 최대 15개, 2026-10-23 바꿈): 그 장의 직접 실을 **한 번에 맞힐 때마다 별 하나**. 직접 실이 3개가 아니면 비율로 센다(맞힌 수 × 3 ÷ 실 수, 반올림). 근무 평정표에는 실마다 "○○–○○ 실을 한 번에 맞혔다 ★ / 다시 골라서 맞혔다 ☆"를 한 줄씩 보여 준다.
- **예측 방향이 틀려도 별을 잃지 않는다.** 2장과 4장의 반전은 일부러 틀리기 쉽게 만든 장치다.
- 프롤로그와 에필로그는 별이 없다.
- **등급**(끝낸 장의 별 비율. 끝내지 않은 장은 '–'로 표시하고 계산에서 뺀다): 견습 분석관(50% 미만) → 정식 분석관(50~84%) → 수석 분석관(85% 이상). 결과 화면은 '근무 평정표'에 별 도장이 찍히는 모양이다. 등급이 오르면 새 사원증 카드가 나온다.
- 틀린 판단은 기록 보관소에 남아 다시 볼 수 있다.

### 5.7 도전 과제

| ID | 이름 | 조건 |
|---|---|---|
| `cuba-paradox` | 쿠바의 역설 | 2장에서 쿠바 위기 뒤 시계가 '멀어졌다'고 예측 |
| `refreeze` | 다시 얼어붙은 시간 | 4장에서 시계가 '가까워졌다'고 예측 |

| `perfect-board` | 완벽한 보드 | 한 장의 직접 실을 모두 첫 시도에 맞힘(2장은 중립 구역 포함) |
| `last-string` | 끝나지 않은 실 | 5장을 끝내고 에필로그에 도달(막 시작 코드로 바로 들어간 경우 제외) |

- 2026-10-23: `enemy-of-enemy`(3장 보너스 질문)와 `collector`(단서 수집)는 없앴다. '적의 적은 친구' 이야기는 3장 미국–중국 실의 한 줄 설명으로 옮겼다. `third-way`는 2장 중립 구역을 다시 정할 때 함께 정한다.
- 알림은 오른쪽 아래 카드(4초). 시계 공개와 보고서 작성 중에는 대기열에 넣었다가 끝난 뒤 띄운다.

### 5.8 난이도: 한 가지 모드

- 난이도를 나누지 않는다. 시작할 때 고르는 단계도 없다.
- 기본 도움: 할 일 카드, '지금 할 일' 쪽지와 진행 막대, 다음에 누를 곳의 빛과 '여기를 누르세요', 형광펜 핵심 구절, 선택지 2개, 틀리면 핵심 구절 다시 보기, 누를 수 있는 물건 아래 라벨(2026-10-23. 2026-10-25부터 '연도'·'시계 설명'은 프롤로그에만, 1장부터는 '문서'만).
- 빠른 학생의 깊이: 도전 과제, 기록 보관소, 낱말 풀이, 표로 보기(실 이력).
- 설정에서 '물건 라벨 숨기기'만 고를 수 있다.

### 5.9 이름, 저장, 이어하기

- **이름:** 시작할 때 **반(1~5반에서 고르기), 번호(1~32번에서 고르기), 이름(글자로 적기)** 세 칸을 채운다(2026-10-23 교사 결정). 셋을 묶어 '반-번호-이름'(예: 2-12-김민수)으로 저장하고 비교한다. 반과 번호의 범위는 `src/data/school.json`에서 고친다. 입력 칸 안내: "반과 번호를 고르고 이름을 적어 주세요. 이 컴퓨터에만 저장되고 다른 곳으로 보내지지 않아요." 빈 칸이 있으면 앞에서부터 하나씩 알려 준다("먼저 반을 골라 주세요."). 이름의 앞뒤 공백은 빼고 비교한다. 여러 반이 같은 크롬북을 써도 이름이 겹치지 않게 하기 위해서다.
- 이름이 쓰이는 곳: 근무 평정표, 사원증 카드, 쓰기 화면, 이어하기 목록 확인.
- **자동 저장:** 단서 수집, 실 걸기, 보고서 제출, 장 끝마다 브라우저 저장소(localStorage)에 저장한다. 저장은 모두 try/catch로 감싸고, 실패해도 게임은 계속된다.
- **이름별 기록:** 한 기기에 여러 학생의 기록을 이름별로 따로 저장한다(공용 크롬북). 기록이 40개를 넘거나 마지막 저장 뒤 60일이 지나면 오래된 것부터 지운다.
- **이어하기:** 이름을 입력하고 '이어하기'를 누르면 그 이름의 기록을 찾아 "○○ · 3장 녹는 얼음 · 별 7개 — 이어서 할까요?"로 확인한 뒤 마지막 저장 지점부터 이어 한다. 다른 학생의 이름 목록은 보여 주지 않는다.
- **처음부터와 같은 이름:** '처음부터'를 눌렀는데 같은 이름의 기록이 있으면 "이 이름의 기록이 있어요. 새로 시작하면 지워집니다"를 두 번 확인한다.
- **2차시의 이어하기:** 저장 지점이 3장 앞(프롤로그~2장)이면 '이어서 하기'와 함께 '3장부터 시작'을 보여 준다. 교사는 2차시에 '핑퐁외교'(또는 이 버튼)를 기본으로 안내한다.
- **내 기록 지우기:** 설정에서 두 번 확인 후 지운다.

### 5.10 막 시작 코드

- 튕기거나 기기가 바뀐 학생이 그 막을 **처음부터** 다시 할 수 있게 한다. 시작 화면의 '막 시작 코드' 칸에 입력한다.
- 코드는 그 막의 핵심 낱말 한글 4글자다. 띄어쓰기는 무시한다. 장 표지에 그 장의 코드를 작게 보여 준다.

| 막 | 코드 |
|---|---|
| 프롤로그 「38선」 | 분할점령 |
| 1장 「갈라진 세계」 | 냉전시작 (2026-10-25 교사 결정: '철의장막'에서 바꿈, 1장 글에 '냉전'이 나온다) |
| 2장 「다른 길」 | 쿠바위기 |
| 3장 「녹는 얼음」 | 핑퐁외교 |
| 4장 「다시 얼어붙다」 | 미중수교 |
| 5장 「장벽이 무너지다」 | 장벽붕괴 |
| 에필로그 「남은 실」(쓰기) | 바늘과실 |

- 코드로 들어가면 그 장의 시작 상태(`startBoard`, `startClock`)에서 출발한다. 이름은 그대로 쓴다.
- 이 기기에 그 이름의 기록이 있으면: 코드로 들어간 장과 그 뒤 장의 진행은 새로 시작하고, 별은 장마다 더 높은 값을 남긴다. 도전 과제와 기록 보관소는 지우지 않는다. 저장 지점은 코드로 들어간 장으로 옮긴다.
- 끝내지 않은 장의 별은 '–'로 표시하고 등급 계산에서 뺀다.
- 실 이력과 쓰기 화면의 단어 상자는 장 데이터로 만들기 때문에 코드로 들어와도 비지 않는다.
- 1차시 끝 화면에는 3장으로 바로 이어지는 버튼을 두지 않고, 다음 시간 코드만 보여 준다.

- 막 제목을 코드로 쓰지 않은 이유: 장 제목은 표지와 연표에 보여서 아직 하지 않은 장으로 쉽게 건너뛸 수 있다. 핵심 낱말 코드는 입력할 때 낱말을 한 번 더 익히는 효과도 있다.

### 5.11 교사 모드 (`?teacher=1`)

- 모든 장이 열린다. 막 시작 코드 목록을 보여 준다.
- 프롤로그 시연용: 글자가 조금 더 크고, 연출을 짧게 한다.
- 밝은 화면(수업 시연) 모드를 기본으로 켠다(프로젝터용).
- '이 기기의 기록 모두 지우기'(두 번 확인).

### 5.12 설정

소리(효과음·음악 따로), 글자 크기 3단계, 큰 이름표, 읽기 쉬운 글꼴, 움직임 줄이기(기기 설정 따름), 가벼운 효과(저사양), 밝은 화면 모드, 물건 라벨, 전체 화면, 내 기록 지우기. 자세한 내용은 아트 계획서 5.5.

### 8.2 메인 책상 화면 (기준 해상도 1536×1024, 3:2)

- 배치는 아트 계획서 4.3을 따른다: 왼쪽 위 창, 가운데 코르크 보드(크림색 차트 종이), 오른쪽 위 벽시계와 명판·넘김 숫자판, 오른쪽 아래 시대 소품, 왼쪽 램프와 일력(연도·장 이름), 책상 위 문서 더미·단서 쪽지·보고서철과 도장, 책상 아래 서랍(기록 보관소).
- 상단 정보 줄은 없다. 연도는 일력, 시계 값은 넘김 숫자판, 별은 보고서철의 근무 평정 카드로 보여 준다. 설정은 왼쪽 위 작은 종이 탭과 Esc.
- 누를 수 있는 물건 아래에는 작은 글자 라벨을 늘 띄운다(문서, 보고서, 기록 보관소, 시계 설명, 연도).
- 책상 왼쪽 아래(문서 더미 밑)에 '지금 할 일' 쪽지와 진행 막대를 **한 줄로** 늘 띄운다("[지금 할 일] 문서 더미를 눌러 새 문서를 읽으세요. | 문서 ●○○ 시계 ○"). 처음에는 책상 가운데 두 줄이었는데, 칸을 너무 차지한다는 교사 의견으로 줄였다(2026-10-25). 그래서 쪽지 문구는 한 줄에 들어가게 짧게 쓴다(20자 안팎). 다음에 누를 곳(문서 더미, 실 이름표, 보고서철) 하나만 빛나고 그 위에 '여기를 누르세요' 말풍선이 뜬다(2026-10-23).
- 좌표는 `layout.json`에서 조정하고, `?layout=1` 좌표 맞추기 도구를 둔다(아트 계획서 4.4).

### 8.4 글자 크기와 화면 축소

## 9. 아트 디렉션 (요약, 자세한 내용은 `docs/art-direction.md`)

- **화풍:** 세피아 잉크 선 + 과슈 색면 + 종이 결의 손그림 그래픽 노블. 그림은 중간 밝기로 받고, 어둠과 빛 웅덩이는 코드가 넣는다. 사진처럼 보이는 그림, 3D, 픽셀 아트는 쓰지 않는다.
- **대표 장면:** 저녁의 방, 왼쪽 램프의 빛 웅덩이. 그 속에서 크림색 차트 종이 위의 실과 붉은 분침의 벽시계만 또렷하다. 실·핀·이름표·시계 판은 모든 조명 층 위에 그려 색이 변하지 않는다.
- **그림 속 글자 금지.** 제목, 로고, 신문 제호, 문서 본문은 모두 코드. 국기, 지도, 실존 인물, 상표, 오륜, 담배는 어떤 그림에도 넣지 않는다.
- **그림 목록:** 필수 25장(기준 그림 1, 방 4, 공용 그림 5, 창밖 7, 표지 7, 종이 결 1) + 여유 2장. M2에 필요한 9장 먼저.
- **표지:** 같은 책상 모서리 위 정물 연작(아트 계획서 6.4). 장 제목과 질문은 코드로 얹는다.
- **작업 순서:** 교사가 ChatGPT로 기준 그림 2장(정물, 1970년대 방)을 시험 → 화풍 확정 → 그림별 프롬프트 전체 작성(Claude) → 생성 → `npm run assets` 빌드.
- 디자인 토큰, 무늬, 레이어 순서, 성능 예산은 아트 계획서 3~5장.

### 10.3 데이터 형식 (TypeScript)

- 한 정보는 한 곳에만 둔다. 막 시작 코드는 각 장의 `code`, 시계 값·캡션·발표 전보 문구는 `clock.json`, 장 시작 보드는 각 장의 `startBoard`에만 둔다.
- `validateData.ts`가 빌드와 테스트에서 검사한다: `startBoard(n)` = 앞 장의 `startBoard` + `edgeTasks` + 매듭 표시 결과, 문서 수(4개 이하)·글자 수(100자)·문장 수(2~3), 핵심 구절이 본문에 그대로 있는지, 직접 실의 선택지 2개, 시계 지점 하나, 글자 수 상한(5.1).

```ts
// src/types.ts와 같다(2026-10-23 쉬운 흐름)
type Rel = 'ALLY' | 'COLD' | 'WAR' | 'TALK' | 'NORMAL' | 'OCCUPY';
type NodeId = 'KR' | 'NK' | 'US' | 'SU' | 'CN' | 'JP' | 'IN' | 'ID' | 'EG' | 'YU' | 'GH';
type Pair = [NodeId, NodeId];

interface Doc {
  id: string;
  type: 'telegram' | 'newspaper' | 'radio' | 'speech' | 'memo' | 'flash';
  year: number;
  yearLabel?: string;          // 예: '1950년 6~10월'
  title: string;
  body: string;                // 2~3문장, 100자 이하, 쉬운 말(해요체). 목록 줄은 제외
  keyPhrase: string;           // body 안에 그대로 있는 핵심 구절. 형광펜으로 보이고, 틀렸을 때 힌트로 다시 보여 준다
  listLine?: string[];         // 중립 구역 나라처럼 따로 보여 주는 목록 줄
  autoOpen?: boolean;          // 장 시작에 자동으로 열림(4-1)
  revealAfter?: string;        // 이 시계 지점 뒤에 도착(5-8)
  source?: string;             // 예: '교과서 222쪽 자료 1'
  outsideTextbook?: boolean;
}

interface EdgeTask {
  pair: Pair;
  from: Rel | null;
  to: Rel;
  // direct: 그 문서를 읽고 나면 학생이 고른다 / auto: 그 문서를 열면 저절로 바뀐다 / reveal: 그 시계 지점을 공개할 때 저절로 바뀐다
  mode: 'direct' | 'auto' | 'reveal';
  year: number;                // 실 이력표에 쓰는 고정 연도
  doc?: string;                // direct, auto: 이 실과 짝인 문서
  point?: string;              // reveal: 이 실을 바꾸는 시계 지점
  options?: Rel[];             // direct: 보여 줄 실 종류 2개(정답 포함)
  label?: string;              // 이름표 덮어쓰기(예: 미국–소련 '협력', 중국–소련 '관계 정상화')
  explanation: string;         // 성공(또는 자동 적용) 시 한 줄 설명
  fray?: boolean;              // 색은 유지하고 균열 표시만(종류가 바뀌면 균열은 사라짐)
}

// clock.json: 시계 데이터는 여기에만 둔다
interface ClockEntry {
  year: number;
  minutes?: number;
  seconds?: number;            // 2026년 85초
  caption: string;             // 공개 경로 캡션(15자 안팎)
  bulletin: { headline: string; reason: string };  // 발표 전보(사실만, 교사 확인). 1947은 '처음 실린 표지' 설명
}

interface ClockCheckpoint {
  id: string;
  mode: 'show' | 'predict';
  year: number;                // clock.json의 year를 가리킴
  pathYears?: number[];        // 공개 때 거쳐 갈 clock.json의 year들(마지막이 year)
  direction?: 'closer' | 'farther';
  unlockAfterDocs?: string[];  // 열어야 하는 문서
  requireEdges?: Pair[];       // 마쳐야 하는 직접 실. 없으면 그 장의 모든 직접 실
  explanation: string;         // 해설 카드(건너뛸 수 없음)
  wrongNote?: string;          // 정정 보도 문구
  achievement?: string;
  annotateEdge?: { pair: Pair; mark: 'hotline' };  // 2장 직통선 매듭(끝까지 남음)
}

type RoomId = 'room-1950s' | 'room-1970s' | 'room-1980s' | 'room-now';

interface Chapter {
  id: string;
  session: 1 | 2;
  title: string;
  period: string;
  code: string;                // 막 시작 코드(한글 4글자). 다른 곳에 두지 않는다
  room: RoomId;
  cover: { image: string; alt: string; question: string };
  startClock: { minutes?: number; seconds?: number } | null;  // 프롤로그는 null(아직 걸리지 않음)
  startNote?: { text: string; signature: string };            // 장 시작 쪽지(2장)
  mission: { lines: string[]; room?: string[]; steps?: string[] };   // '할 일' 카드: 상황 설명(1~2문장씩). room·steps는 장마다 바꿀 때만(프롤로그)
  nodeLabels?: Partial<Record<NodeId, string>>;   // 핀 이름 덮어쓰기(프롤로그 '38선 이남')
  nodeSides?: Partial<Record<NodeId, LabelSide>>; // 핀 이름표 방향 덮어쓰기(프롤로그 남한: 왼쪽)
  startBoard: { pair: Pair; rel: Rel; fray?: boolean; mark?: 'hotline'; label?: string }[];
  backgroundEdges: { pair: Pair; rel: Rel; weakened?: boolean; appearAfterDoc?: string; note?: string }[];
  documents: Doc[];            // 배열 순서 = 도착 순서. 앞 문서의 실을 바꿔야 다음 문서가 온다(3개)
  edgeTasks: EdgeTask[];
  clock: ClockCheckpoint[];    // 시계는 장마다 한 번
  endEvents?: ('renameSU' | 'weakenNKSU' | 'greenCascade')[];  // 5장 끝. greenCascade는 이미 녹색인 실을 다시 울리는 확인 연출
  epilogueBoard?: { pair: Pair; style: 'undyed'; label: string; caption: string };  // 에필로그 남북 실
  window: { image: string; caption: string; alt: string; crop?: { x: number; w: number } };
}

interface SaveSlot {
  name: string;                // '반-번호-이름'. 앞뒤 공백 제거 후 비교
  updatedAt: number;           // 60일이 지나거나 40개를 넘으면 오래된 것부터 정리
  chapterId: string;           // 저장 지점(막 시작 코드로 들어가면 그 장으로 옮김)
  progress: unknown;           // 읽은 문서, 실, 시도 횟수, 보고서
  stars: Record<string, number | null>;   // null = '–'(끝내지 않음, 등급 계산에서 제외)
  achievements: string[];
  archive: unknown[];          // 틀린 판단 기록
}
```

## 11. 접근성과 성능

- 키보드: Tab 순서 문서 → 단서 → 핀과 실 → 보고서. Enter로 고르고, 숫자 키로 실 종류, Esc로 설정. 포커스 링은 모든 층 위.
- 마우스를 올려야만 보이는 기능은 없다(태블릿). 모든 기능은 탭과 Enter로 쓸 수 있다.
- `prefers-reduced-motion`과 설정의 움직임 줄이기: 이동은 크로스페이드, 바늘과 숫자는 바로 바뀜, 입자·시차·흔들림·맥박 끔.
- 색만으로 의미를 전달하지 않는다(무늬, 이름표). 흑백 화면과 0.63배 축소에서 실 6종이 구분되는지 검사한다.
- 창밖 장면과 표지에 대체 텍스트(`alt`). 중요한 소리에 화면 신호.
- 성능 예산(아트 계획서 5.6): 전체 화면 그림 WebP 300KB 이하, 장 시작 시 1.5MB 이하, 게임 전체 그림 10MB 이하. 실행 중 필터와 블렌드 합성 대신 빌드 때 색을 굽는다.

### 13.2 교육 윤리

- **허구 고지:** 타이틀(작게), 프롤로그 첫 화면(크게, '확인'), 크레딧에 "분석실, 본샘일보, 당직자는 수업을 위해 만든 가상의 설정입니다. 문서 속 사건, 연도, 시계 값은 실제 기록을 따릅니다."
- **발표 전보:** 원자 과학자 회보의 발표 전보는 형식(전보 모양)만 게임의 연출이고, 내용은 회보 발표의 사실만 쓴다.
- **AI 고지:** 타이틀과 크레딧에 "이 게임의 그림은 AI로 만든 일러스트이며 실제 역사 사진이 아닙니다." 창밖 장면에 'AI 일러스트 · 실제 사진 아님'.
- 운명의 날 시계는 과학자 단체의 평가이며 실제 측정값이 아니라는 점을 게임 안에 밝힌다(5.4).
- 교과서의 사진과 본문은 그대로 옮기지 않는다. 게임 문서는 새로 쓰고 교과서 쪽수만 표시한다.
- 실존 인물(4-6 덩샤오핑 포함)의 얼굴을 AI로 그리지 않는다. 문서 속 글로만 등장시킨다.
- 전쟁과 여객기 격추 같은 비극은 간접적으로 묘사한다.
- 국기와 지도는 어떤 그림에도 넣지 않는다. 지도가 필요하면 검증된 공개 데이터로 만든 코드 SVG를 쓴다.
- 에필로그 질문과 쓰기는 정답을 정하지 않는다. 남북 관계나 현재 정책에 대해 특정 입장을 제시하지 않는다. 보드도 1991년 이후 남북 관계를 단정하지 않는다(색이 빠진 실과 '지금은?').
- **개인정보:** 학생 이름은 그 기기의 브라우저에만 저장하고 어디로도 보내지 않는다. 학생 글은 저장하지 않는다(종이 활동지). 다른 학생의 이름 목록을 보여 주지 않는다. 내 기록 지우기와 교사용 기기 기록 지우기를 둔다. `TODO(교사 확인: 학교 개인정보 지침)`
