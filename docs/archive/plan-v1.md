# 「자정의 분석실」 게임 기획서 (가제)

> 중학교 역사① Ⅶ-01 「냉전 체제와 제3 세계의 형성」 수업용 웹 게임
> 관계도 퍼즐(「선의 색이 바뀐다」)과 운명의 날 시계 예측 게임을 하나로 결합한 기획

## 0. 이 문서를 읽는 Claude Code에게

- 이 문서는 게임의 기획서이자 작업 지시서다. 구현 전에 끝까지 읽고, 모호한 부분은 추측하지 말고 질문한다.
- **역사적 사실을 지어내지 않는다.** 이 문서에 없는 연도, 사건, 인용문이 필요하면 `TODO(교사 확인)` 표시를 남기고 넘어간다.
- 화면에 보이는 모든 한국어 텍스트(문서 본문, UI 문구, 설명)는 코드에 직접 쓰지 않고 `src/data/` 아래 데이터 파일로 분리한다. 교사가 코드를 몰라도 내용을 고칠 수 있어야 한다.
- 개발은 10장의 순서를 따른다. **3장(녹는 얼음) 버티컬 슬라이스를 먼저 완성**하고, 그 틀에 나머지 장을 채운다.
- 그림 파일이 아직 없으면 같은 크기의 자리표시 이미지를 쓰고, 파일명은 7.5의 규칙을 그대로 따른다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 한 줄 소개 | 1945년 서울의 국제 정세 분석실에 앉은 분석관이 되어, 문서를 읽고 나라 사이의 관계를 실로 잇고, 운명의 날 시계의 움직임을 예측하는 추론 게임 |
| 대상 | 중학교 2학년. 역사 학습을 어려워하는 학생이 다수 |
| 수업 | 3차시 (1차시: 프롤로그~1장, 2차시: 2~3장, 3차시: 4~5장과 에필로그). 한 장에 15~20분 |
| 플랫폼 | 웹 브라우저 (학교 PC의 크롬·웨일, 크롬북, 가로 모드 태블릿) |
| 장르 | 데스크 시뮬레이션 + 추론 퍼즐 |

### 학습 목표

1. 냉전의 형성부터 해체까지를 '갈라짐 → 뜨거워짐 → 다른 길 → 녹음 → 다시 얼어붙음 → 무너짐'이라는 하나의 흐름으로 설명할 수 있다.
2. 냉전을 개별 사건의 나열이 아니라 **나라 사이 관계의 변화**로 이해한다.
3. 사건(원인)이 관계를 바꾸고, 관계의 변화가 세계의 위험도(결과)를 움직인다는 인과 관계를 추론할 수 있다.
4. 세계의 냉전이 끝난 뒤에도 한반도에는 분단이 남아 있다는 점에서 탈냉전의 의미와 한계를 생각해 본다.

## 2. 핵심 콘셉트

### 2.1 두 게임의 결합: 실은 원인, 시계는 결과

- **관계 보드(「선의 색이 바뀐다」):** 나라 핀 사이에 색 실을 걸어 관계를 표시한다. 문서에서 찾은 단서가 있어야 실을 걸 수 있다.
- **운명의 날 시계:** 미국 원자 과학자 회보(Bulletin of the Atomic Scientists)가 1947년부터 발표해 온 실제 시계. 플레이어는 시계가 자정(핵전쟁)에 가까워졌는지 멀어졌는지 예측한다.
- **연결 고리:** 시계를 예측할 때 반드시 관계 보드에서 근거가 된 실 하나를 지목한다. 학생이 "어떤 관계의 변화가 세계를 더 위험하게 또는 더 안전하게 만들었는가"를 스스로 연결하게 하는 장치다.

### 2.2 고정된 시점: 서울의 분석실

- 플레이어는 처음부터 끝까지 같은 방, 같은 책상에 앉은 분석관이다. 역할이 바뀌지 않아 흐름이 끊기지 않는다.
- 한반도는 '창문'이고 배우는 대상은 '창밖의 세계'다. 교과서가 세계사(역사①)이므로 모든 퍼즐은 세계의 사건을 근거로 풀어야 한다.
- 이야기 요소는 창밖 장면에만 담는다. 플레이의 중심은 읽기, 잇기, 판단하기다.

### 2.3 참고한 게임 (구조만 참고, 디자인은 따라 하지 않는다)

- 『Papers, Please』: 책상 위 문서를 읽고 판단하는 화면 구성
- 『The Case of the Golden Idol』: 문서에서 단어를 모아 추론에 쓰는 방식
- 『Twilight Struggle』: 냉전의 긴장도를 트랙 하나로 보여 주는 장치

## 3. 핵심 플레이 루프

한 장(챕터)은 다음 네 단계로 진행된다.

1. **읽기:** 문서함에 전보, 신문, 라디오 방송, 연설문이 도착한다. 문서를 열어 핵심 구절을 형광펜으로 칠하면 '단서 단어'가 된다.
2. **잇기:** 관계 보드에서 두 나라 사이의 실 색을 정한다. 실을 바꾸려면 단서 단어 하나를 근거로 붙여야 하며, 근거가 맞지 않으면 실이 걸리지 않는다.
3. **보고하기:** 시계 예측 지점에 도달하면 보고서를 쓴다. ① 자정에 가까워졌는가/멀어졌는가를 고르고 ② 근거가 된 실 하나를 지목한다.
4. **확인하기:** 시계 바늘이 실제 기록대로 움직이고, 보고서가 신문 1면 헤드라인으로 인쇄되며, 창밖 장면이 그 시대 한반도의 모습으로 바뀐다.

장이 끝나면 별점(1~3개)이 매겨지고 다음 장이 열린다.

## 4. 시스템 상세

### 4.1 문서와 단서

- 문서 형식: `telegram`(전보), `newspaper`(신문), `radio`(라디오 받아쓰기), `speech`(연설문), `memo`(타자 문서)
- 각 문서에는 1~2개의 단서 구절이 숨어 있다. 플레이어가 드래그로 칠하거나 단어를 탭하면 단서 보관함에 들어간다.
- 단서가 아닌 구절을 칠하면 아무 일도 일어나지 않는다(감점 없음).
- 문서마다 `required`(필수)/`optional`(선택) 표시가 있다. 견습 모드에서는 필수 문서만 읽어도 장을 끝낼 수 있다.
- 문서 본문은 학생 수준에 맞게 3~5문장으로 쓴다. 본문 글자 크기는 최소 18px.
- 일부 문서는 시계 예측 **뒤에** 공개된다(`revealAfter`). 예: 2장의 부분 핵실험 금지 조약 문서는 쿠바 위기 예측 뒤에 해설로 나온다.

### 4.2 관계 보드

**나라 핀 (기본 6개)**

| ID | 이름 | 비고 |
|---|---|---|
| `KR` | 남한 | 프롤로그에서는 '38선 이남' |
| `NK` | 북한 | 프롤로그에서는 '38선 이북' |
| `US` | 미국 | |
| `SU` | 소련 | 5장 끝에 '러시아'로 이름이 바뀌는 연출 |
| `CN` | 중국 | 프롤로그에서는 '국공 내전 중'으로 흐리게 표시 |
| `JP` | 일본 | 배경 실 전용 |

**실의 종류**

| 값 | 이름 | 의미 | 표현 |
|---|---|---|---|
| `ALLY` | 같은 편 | 동맹, 같은 진영 | 청색 실 |
| `COLD` | 대립 | 적대하지만 직접 싸우지 않음 (냉전) | 회색 실 |
| `WAR` | 전쟁 | 무력 충돌 (열전) | 붉은 실 |
| `TALK` | 대화 | 대화와 긴장 완화의 시작 | 황동색 실 |
| `NORMAL` | 수교·협력 | 국교 수립, 관계 정상화 | 녹색 실 |
| `OCCUPY` | 점령 | 프롤로그 전용 (분할 점령) | 회색 점선 |

- 실이 없는 상태 = 아직 관계가 정해지지 않음
- **균열 표시(`FRAY`):** 색은 그대로 두고 실이 해어지는 연출. 2장에서 중국–소련 실에 사용 (3장 변화의 복선)
- **배경 실:** 퍼즐 대상이 아닌 고정 실. 흐리게 표시하며 클릭할 수 없다.
  - `US–KR` 같은 편 (1장~), `US–JP` 같은 편 (1장~), `NK–SU` 같은 편 (1장~4장, 5장에는 '약화' 점선), `NK–CN` 같은 편 (1장에서 중국군 참전 문서를 읽으면 등장)

**중립 구역 (2장 전용)**

- 보드 바깥쪽에 '어느 편도 아닌 나라' 구역이 열린다.
- 인도(`IN`), 인도네시아(`ID`), 이집트(`EG`), 유고슬라비아(`YU`), 가나(`GH`) 핀을 단서와 함께 중립 구역에 놓는다.
- 제3 세계를 따로 떨어진 주제가 아니라 냉전 구도에 대한 반응으로 보이게 하는 장치다.

**실을 바꾸는 조작**

1. 두 나라 사이의 실(또는 빈 자리)을 클릭한다.
2. 실 색 선택 메뉴에서 색을 고른다.
3. 단서 보관함에서 근거 단서를 실 위로 끌어다 놓는다.
4. 판정: 색과 근거가 모두 맞으면 실이 걸리고 '팅' 소리와 함께 한 줄 설명이 나온다. 틀리면 실이 흔들리며 원래대로 돌아간다.

### 4.3 보고서와 시계

- 장마다 시계 지점(checkpoint)이 1~2개 있다. 종류는 두 가지다.
  - `show`: 값만 보여 준다(예측 없음).
  - `predict`: 보고서를 쓴다.
- 보고서 작성 순서
  1. "시계는 자정에 가까워졌을까, 멀어졌을까?" 두 버튼 중 하나 선택
  2. "가장 큰 이유가 된 실은?" 보드에서 실 하나를 클릭 (`bestEdges`에 정해진 실이면 정답. `bestEdges`가 비어 있는 지점은 이 단계를 건너뜀)
  3. 제출
- 공개 연출: 시계 바늘이 `path`에 적힌 중간값을 차례로 거쳐 최종값까지 움직인다. 중간값마다 연도와 짧은 설명이 표시된다.
- 시계 크기와 초침 소리는 자정에 가까울수록 커지고 빨라진다.
- 시계 판정은 방향만 본다. 분 단위 숫자를 맞힐 필요는 없다.

### 4.4 결과 연출

- **신문 1면:** 보고서 제출 뒤 플레이어의 판단이 신문 헤드라인으로 인쇄된다.
  - 템플릿 예: `[분석실 보고] {연도}년, 세계는 자정에서 {멀어졌다/가까워졌다}: {실 이름}의 변화에 주목`
  - 판단이 틀렸으면 아래에 '정정 보도' 박스로 실제 결과를 보여 준다.
- **창밖 장면:** 장이 끝나면 창문 영역의 그림이 그 시대 한반도 장면으로 천천히 바뀐다. 짧은 캡션 1~2문장.
- **챕터 전환:** 책상 위 소품과 방의 색감이 다음 시대로 바뀌는 연출 (7.3 참고).

### 4.5 점수와 등급

- 승패는 없다. 틀려도 게임은 계속된다.
- 장별 별점
  - ★★★: 모든 실을 두 번 안에 맞힘 + 모든 시계 예측 정답 + 근거 실 정답
  - ★★: 시계 예측 중 하나 이상 정답
  - ★: 장 완료
- 전체 분석관 등급(총 별점 비율): 견습 분석관(50% 미만) → 정식 분석관(50~84%) → 수석 분석관(85% 이상)
- 틀린 판단은 기록 보관소에 남아 다시 볼 수 있다.

### 4.6 도전 과제

| ID | 이름 | 조건 |
|---|---|---|
| `cuba-paradox` | 쿠바의 역설 | 2장에서 쿠바 위기 뒤 시계가 '멀어졌다'고 예측 |
| `enemy-of-enemy` | 적의 적 | 3장 보너스 질문에서 미국–중국을 가깝게 만든 실로 중국–소련 실을 지목 |

| `third-way` | 제3의 길 | 2장 중립 구역에 다섯 나라를 모두 올바른 단서로 배치 |
| `collector` | 단서 수집가 | 한 장에서 선택 문서까지 모든 단서 수집 |

| `chief-analyst` | 수석 분석관 | 전체 등급 수석 달성 |

### 4.7 난이도

| 항목 | 견습 분석관 (기본) | 수석 분석관 |
|---|---|---|
| 단서 구절 | 마우스를 올리면 살짝 빛남 | 빛나지 않음 |
| 실 색 선택지 | 그럴듯한 2~3개만 표시 | 6개 모두 표시 |
| 필수 문서 | 필수 문서만 읽어도 진행 가능 | 모든 문서 열람 필요 |
| 힌트 | 같은 실에서 2회 틀리면 자동 힌트 | 힌트 버튼(사용 시 별점 하나 차감) |

### 4.8 저장

- 장이 끝날 때마다, 그리고 실을 하나 걸 때마다 브라우저 저장소(localStorage)에 자동 저장한다. 저장 실패에 대비해 try/catch로 감싼다.
- 타이틀 화면에서 '이어하기' 제공.
- 교사용: 주소 뒤에 `?teacher=1`을 붙이면 모든 장이 열린 상태로 시작 (수업 시연용).

```
                     보고서 → 시계 공개 → 신문 1면 → (다음 시계 지점 또는) 창밖 장면 → 장 결과(별점) → 다음 장
```

## 7. 아트 디렉션

### 7.1 원칙: 배경은 그림, 움직이는 건 코드

- **그림(ChatGPT 이미지 생성):** 방 배경, 창밖 장면, 챕터 표지, 타이틀 배경, 빈 문서 종이 질감
- **코드:** 나라 핀, 실, 시계 바늘과 숫자, 문서 본문, 단서, 버튼, 그래프, 모든 UI 문구

**한글 텍스트 방침:** 최근 이미지 모델은 한글을 잘 쓰므로, 챕터 표지 제목과 타이틀 로고처럼 바뀌지 않는 글자는 그림에 넣어도 된다. 단, 문서 본문과 UI 문구는 반드시 코드로 쓴다. 사실 확인 뒤 고칠 일이 많고, 형광펜·클릭 같은 상호작용이 필요하며, 화면 크기가 바뀌어도 선명해야 하기 때문이다.

### 7.2 화풍

- **그래픽 노블풍 2D 일러스트:** 가는 잉크 외곽선, 납작한 색면, 은은한 종이 질감, 바랜 색감
- 사진처럼 사실적인 그림은 쓰지 않는다. 학생이 AI 그림을 실제 역사 사진으로 오해하지 않도록 누가 봐도 그림이어야 한다.
- 픽셀 아트는 쓰지 않는다. 생성할 때마다 픽셀 격자가 달라져 장면을 이어 붙이면 티가 난다.
- 카메라는 하나로 고정: 책상에 앉은 분석관이 정면 벽을 바라보는 1인칭 시점

### 7.3 시대별 연출

| 방 | 쓰는 장 | 책상 소품 | 색감 | 문서 글꼴 느낌 |
|---|---|---|---|---|
| 1950년대 | 프롤로그~2장 | 진공관 라디오, 타자기, 잉크병 | 올리브, 바랜 갈색 | 타자기 |
| 1970년대 | 3장 | 흑백 텔레비전, 다이얼 전화기 | 빛바랜 주황, 갈색 | 타자기 |
| 1980년대 | 4~5장 | 컬러 텔레비전, 팩스, 버튼식 전화기 | 푸른빛 도는 회청색 | 도트 프린터 |
| 지금 | 에필로그 | 노트북, 스마트폰 | 밝은 중립색 | 현대 고딕 |

**실 색 (모든 시대 공통, 의미가 바뀌지 않음)**

**디자인 원칙**

- 화려함은 한곳에만 쓴다. **벽시계와 실**이 이 게임의 주인공이고, 나머지 UI는 조용하고 절제되게 둔다.
- 시대 전환 연출은 한 번에 크게 한다(방 전체가 바뀌는 순간). 버튼마다 효과를 넣지 않는다.
- 색만으로 의미를 전달하지 않는다. 실에는 색과 함께 짧은 이름표(예: '대화')를 붙여 색각 이상 학생도 구분할 수 있게 한다.
- 키보드 조작과 `prefers-reduced-motion`을 지원한다.

**만들 때 주의**

- 기준 그림 한 장을 먼저 완성하고, 나머지는 반드시 그 그림을 첨부해 "같은 구도, 같은 화풍"으로 요청한다.

- 비극적인 사건(전쟁 피해, 여객기 격추)은 사고 장면 대신 사람들의 뒷모습이나 뉴스를 지켜보는 모습으로 간접 묘사한다.
- 올림픽 오륜, 기업 로고 같은 상표는 넣지 않는다.

### 9.3 데이터 형식 (TypeScript)

```ts
type Rel = 'ALLY' | 'COLD' | 'WAR' | 'TALK' | 'NORMAL' | 'OCCUPY';
type NodeId = 'KR' | 'NK' | 'US' | 'SU' | 'CN' | 'JP' | 'IN' | 'ID' | 'EG' | 'YU' | 'GH';
type Pair = [NodeId, NodeId];

interface Doc {
  id: string;
  type: 'telegram' | 'newspaper' | 'radio' | 'speech' | 'memo';
  year: number;
  title: string;
  body: string;            // 3~5문장. 교사 작성 또는 검토
  clues: string[];         // body 안에 그대로 들어 있어야 하는 구절
  required: boolean;
  revealAfter?: string;    // 이 시계 지점 뒤에 공개
  source?: string;         // 예: '교과서 222쪽 자료 1'
}

interface EdgeTask {
  pair: Pair;
  from: Rel | null;
  to: Rel;
  evidence: string[];      // 정답으로 인정하는 단서 (하나만 붙이면 됨)
  explanation: string;     // 성공 시 한 줄 설명
  fray?: boolean;          // 색은 유지하고 균열 표시만
}

interface NeutralTask {     // 2장 중립 구역
  node: NodeId;
  evidence: string[];
}

interface ClockStep { year: number; minutes?: number; seconds?: number; caption: string; }

interface ClockCheckpoint {
  id: string;
  mode: 'show' | 'predict';
  year: number;
  minutes?: number;
  seconds?: number;        // 에필로그(85초)처럼 초 단위일 때
  direction?: 'closer' | 'farther';
  path?: ClockStep[];      // 공개 시 거쳐 갈 중간값
  bestEdges?: Pair[];      // 비어 있으면 근거 실 단계 생략
  unlockAfterDocs?: string[];
  explanation: string;
  achievement?: string;
}

interface Chapter {
  id: string;
  title: string;
  period: string;
  room: 'room-1950s' | 'room-1970s' | 'room-1980s' | 'room-now';
  startBoard: { pair: Pair; rel: Rel; fray?: boolean }[];
  backgroundEdges: { pair: Pair; rel: Rel; weakened?: boolean }[];
  documents: Doc[];
  edgeTasks: EdgeTask[];
  neutralTasks?: NeutralTask[];
  clock: ClockCheckpoint[];
  bonusQuestion?: { prompt: string; answer: Pair; achievement?: string };
  window: { image: string; caption: string };
  closingQuestion?: string;
}
```

## 10. 개발 순서

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| M0 준비 | 프로젝트 생성, 폴더 구조, 9.3의 타입, 3:2 화면 축소·레터박스 | 빈 책상 화면이 여러 해상도에서 비율을 유지하며 뜸 |
| **M1 버티컬 슬라이스** | 3장 하나를 자리표시 그림으로 끝까지 플레이 가능하게 | 아래 체크리스트 전부 통과 |
| M2 그림 적용 | `room-1970s`, `window-ch3`, 문서 종이 3종 적용, `layout.json` 좌표 맞춤 | 그림 위 보드·시계·창문 영역이 정확히 겹침 |
| M3 전체 챕터 | 나머지 장 데이터 입력(교사 검토 후), 챕터 선택 화면, 장 전환 연출 | 프롤로그부터 에필로그까지 이어서 플레이 가능 |
| M4 메타 기능 | 기록 보관소(시계 그래프, 지난 문서, 지난 보고서), 도전 과제, 난이도 | 4.5~4.7 규칙대로 동작 |
| M5 다듬기 | 사운드, 타이틀, 시대 전환 연출, 접근성 점검 | 키보드만으로 한 장을 끝낼 수 있음 |
| M6 수업 테스트 | 학생 3~4명 시험 플레이, 한 장 소요 시간 측정 | 한 장 15~20분 안에 끝남. 넘으면 선택 문서를 줄임 |

### M1 체크리스트

- [ ] 문서함의 문서를 열고 닫을 수 있다.
- [ ] 문서의 단서 구절을 칠하면 단서 보관함에 들어간다. 단서가 아닌 구절은 반응하지 않는다.
- [ ] 실을 클릭해 색을 고르고 단서를 붙일 수 있다. 맞으면 실이 걸리고, 틀리면 원래대로 돌아간다.
- [ ] 같은 실에서 두 번 틀리면 견습 모드 힌트가 뜬다.
- [ ] `unlockAfterDocs`를 모두 읽고 관련 실을 모두 맞히면 보고서 버튼이 활성화된다.
- [ ] 보고서에서 방향과 근거 실을 고를 수 있고, 시계가 `path`를 따라 움직인다.
- [ ] 신문 1면이 판단에 따라 다르게 인쇄되고, 틀렸을 때 정정 보도가 나온다.
- [ ] 보너스 질문과 `enemy-of-enemy` 도전 과제가 동작한다.
- [ ] 장 결과 화면에 별점이 4.5 규칙대로 나온다.
- [ ] 새로고침해도 진행 상황이 유지된다.
- [ ] 화면의 모든 한국어 문구가 데이터 파일에서 온다(컴포넌트에 하드코딩된 문구 없음).

### 11.2 교육 윤리

- 타이틀 또는 크레딧에 다음 문구를 넣는다: "이 게임의 그림은 AI로 만든 일러스트이며 실제 역사 사진이 아닙니다."
- 운명의 날 시계는 과학자 단체의 평가라는 점을 게임 안에 밝힌다.
- 교과서의 사진과 본문은 그대로 옮기지 않는다. 게임 문서는 교과서 내용을 바탕으로 새로 쓰고, 교과서 쪽수만 표시한다.
- 실존 인물의 얼굴을 AI로 그리지 않는다.
- 전쟁과 여객기 격추 같은 비극은 간접적으로 묘사한다.
- 에필로그의 마지막 질문은 정답을 정하지 않는다. 남북 관계나 현재 정책에 대해 특정 입장을 제시하지 않는다.
