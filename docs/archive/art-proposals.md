## 1. 한 줄 콘셉트와 참고 작품

**상점 문구:** 1945년 서울, 신문사 꼭대기 층에 불 켜진 방 하나가 있다. 주인은 여러 번 바뀌어도 코르크 보드와 벽시계는 80년 동안 그 자리를 지켰다. 전보와 라디오에서 단서를 찾아 나라와 나라 사이에 실을 걸고, 오늘 밤 세계가 자정에 얼마나 가까운지 판단하라.

| 작품 | 빌려 오는 것 |
|---|---|
| **Papers, Please** (Lucas Pope, 2013) | 책상 위로 서류를 끌어와 펼치는 손맛, **도장을 쾅 찍는 판단의 순간**, 하루가 시작될 때 보여 주는 짧은 신문. 우리 게임에서는 보고서 도장과 신문 1면에 쓴다. |

## 2. 배경 설정 (세계관)

### 2.1 분석실
- 가상의 신문사(가칭 「새벽신보」, `TODO(교사 확인: 실존 신문 이름과 겹치지 않는지)`) 꼭대기 층의 작은 방이다. 외신부 옆에 딸린 **'국제 정세 분석실'**이다.
- 하는 일은 외신 전보, 해외 라디오 받아쓰기, 다른 신문, 연설문을 모아 "오늘 밤 세계는 어디로 가는가"를 판단하는 것이다. 판단은 다음 날 아침 1면 해설이 된다. 그래서 신문 1면 결과 연출이 설정 안에서 그대로 설명된다.
- **자정은 마감 시각이다.** 분석관은 밤마다 자정 전에 보고서를 송고해야 한다. 벽에는 과학자들이 말하는 또 하나의 '자정', 운명의 날 시계가 걸려 있다. 대사로 설명하지 않고 제목의 이중 의미로만 남긴다.
- 정치 기사는 다루지 않는 방이다. 세계와 한반도를 둘러싼 국제 관계만 다룬다(교과서 범위와 같다).

### 2.2 분석관: 한 사람이 아니라 '7번 자리'
- 플레이어는 처음에 **호출 부호**(예: 이니셜 두 글자, 실명 아님)를 정한다. 분석관 얼굴과 손은 끝까지 나오지 않는다(AI가 손을 잘 못 그리는 문제도 함께 피한다).
- 장마다 다른 시대의 당직자가 이 자리에 앉는다. 사람은 바뀌지만 **자리, 보드, 시계는 그대로다.** 인계 일지 서명란에는 시대마다 같은 호출 부호가 쌓인다. 한 사람이 80년을 산 것이 아니라 한 자리를 이어받는 계보다. 그래서 1945년에서 지금까지 같은 시점이 자연스럽다.

### 2.3 시계
- 사실: 1947년 미국의 원자 과학자 회보가 잡지 표지에 이 시계를 처음 실었다(자정 7분 전).
- 허구: 분석실은 그 시계를 본뜬 벽시계를 만들어 걸고, 회보가 발표할 때마다 손으로 바늘을 옮겨 왔다. 시계 아래에는 **넘김식 숫자판**("자정까지 7분")이 붙어 있다.
- 프롤로그 끝 문구는 「1947년, 미국의 과학자들이 잡지 표지에 시계를 그렸다. 분석실은 그 시계를 벽에 걸었다.」로 고칠 것을 제안한다. 기존 문구는 과학자들이 직접 벽에 건 것처럼 읽힌다. `TODO(교사 확인)`
- 회보가 디자인한 원래 시계 그림은 따라 그리지 않는다. 일반적인 둥근 벽시계로 만든다.

### 2.4 장과 장을 잇는 장치 (학습 장치)

| 장치 | 방 안의 물건 | 학습 기능 |
|---|---|---|
| **당직 인계 일지** | 장이 시작될 때 책상 위에 놓인 공책. 지난 장 당직자의 메모 3줄과 '다음 당직자에게 남기는 질문' 1줄 | **복습과 복선.** 3줄은 지난 장 보드에서 바뀐 실을 플레이어 기록에서 자동으로 뽑는다. 질문 1줄은 교사가 데이터로 쓴다. 예: 2장 끝 "중국–소련 실이 해어지고 있다. 다음 당직자는 이 실을 지켜볼 것." 이 메모가 3장으로 이어진다. |
| **어젯밤 확인** | 일지 아래 붙은 쪽지 문제 1개(예: "1963년 미국–소련 실은 무슨 색이었나?") | 인출 연습. **점수에 넣지 않고** 설정에서 끌 수 있다. 시스템을 바꾸지 않는 표현층 장치다. |
| **실의 흔적** | 실을 바꾸면 이전 실 자리에 연필 자국과 작은 메모("1953 대립")가 흐리게 남는다. 핀 두 개를 고르면 그 실의 역사가 색 띠로 보인다. | 관계가 어떻게 변해 왔는지 눈으로 따라간다. 화면이 복잡해지지 않도록 마우스를 올리거나 포커스했을 때만 보인다. |
| **기록 띠** | 벽 아래, 책상 위에 가로로 붙인 긴 모눈 기록지 | 기획서의 '기록 보관소 시계 그래프'를 방 안 물건으로 바꾼 것. 장마다 시대색 구간이 붙고 시계 값이 점으로 찍힌다. 연표와 결과 그래프가 늘 보인다. |
| **보드의 나이** | 장이 지날수록 압정 구멍, 바랜 테이프, 해진 모서리가 늘어난다 | 시간이 흘렀다는 감각을 준다. 보드는 하나이므로 코드로 덧칠한다. |
| **창밖의 독자들** | 장 끝 창밖 장면 | 창밖 장면은 대부분 **뉴스를 받아 드는 사람들**이다(라디오, 호외, 전파상 TV). 분석실의 판단(원인)과 거리 사람들의 삶(결과)이 이어진다. |

### 2.5 에필로그의 의미
- 지금의 당직자가 낮에 방에 들어온다. 80년 만에 처음으로 낮이다. 보드에는 1992년의 실이 먼지를 쓴 채 그대로 있다. 일지에는 "1991년 이후 시계는 여러 차례 조정되었다"는 메모가 있다.
- 시계 예측(85초)을 마치면 **인계 일지의 마지막 쪽이 비어 있다.** 플레이어가 "이 실은 왜 아직 남아 있을까?"에 대한 생각을 적는다(정답 없음, 저장만 한다).
- 마지막 장면: 램프가 꺼지고 방이 어두워지는데 남한–북한 황동색 실만 희미하게 맥박친다. 크레딧은 80년치 인계 일지를 넘기며 올라간다. AI 일러스트 고지와 "분석실·분석관·신문사는 수업을 위해 지어낸 허구이며, 문서 속 사건은 실제 역사입니다."라는 고지를 넣는다.
- 창밖(휴전선 철책과 들판)에는 사람이 없다. 이 실의 소식은 아직 도착하지 않았다는 정도로만 읽히게 한다. 특정 입장은 제시하지 않는다.

## 3. 비주얼 아이덴티티

### 3.1 화풍
- **선:** 짙은 갈색~검정 잉크 펜 선. 굵기가 조금씩 흔들리는 손맛을 살리고, 외곽선만 쓰며 해칭은 그림자에만 조금 넣는다.
- **면:** 과슈와 수채로 칠한 절제된 색면. 한 그림에 주요 색 5~6개.
- **질감:** 그림 전체에 종이 결을 넣고, 코드로 정지 그레인을 한 겹 더 얹는다. 모든 그림을 같은 그레인으로 묶는 역할이다.
- **금지:** 사진 같은 사실감, 3D 렌더 느낌, 애니메이션 셀, 픽셀 아트, 그림 안의 글자·로고·국기.

### 3.2 조명과 재질
- **광원 규칙:** 방 안의 빛은 시대 광원 하나(램프, 형광등, LED)와 창에서 들어오는 빛뿐이다. 보드 가운데와 시계에 빛이 가장 많이 닿게 한다.
- **스프라이트 규칙:** 보드와 시계 그림은 **고른 중성 조명**으로 만들고 조명은 코드로 입힌다. 그래야 장마다 바뀌는 빛 색에 자연스럽게 물든다.
- **고정 재질:** 짙은 호두나무(책상, 보드 틀, 시계 테), 코르크, 낡은 놋쇠(압정, 명판). 80년 동안 바뀌지 않는 것들이다. 시대가 바뀌면 벽 마감, 광원, 소품만 바꾼다.

### 3.4 시각적 위계 (시계와 실이 주인공)
1. **밝기:** 램프 빛 웅덩이를 보드 가운데와 시계에 둔다. 나머지에는 비네트를 준다.
2. **채도:** 높은 채도는 실 다섯 색과 시계의 빨강에만 쓴다.
3. **움직임:** 늘 움직이는 것은 시계 초침과 실의 미세한 흔들림뿐이다. 나머지는 정지해 있다.
4. **크기:** 보드가 화면의 약 40%, 시계 지름은 약 300px이다.
5. **실 표현:** 실은 2.5~4px 굵기에 아이보리 `#F4EFE4` 1px 테두리와 2px 그림자를 준다. 무늬로도 구분한다(같은 편 = 꼰 이중선, 대립 = 실선에 짧은 서리 눈금, 전쟁 = 굵은 실선과 매듭, 대화 = 긴 점선, 수교·협력 = 굵게 꼰 선, 점령 = 회색 점선). 이름표는 실 가운데에 다는 작은 종이 태그로 한다.

### 3.5 화면 배치 (1536×1024, 좌표는 `layout.json`에서 조정)

```
┌──────────────────────────────────────────────────────────────┐
│[일력 1971]       [놋쇠 명판: 국제 정세 분석실]         ( 운명의 )   │
│ ┌──────────── 코르크 보드 (약 1000×560) ───────────┐  (  날 시계 )  │
│ │ 나라 핀(이름 태그, 국기 없음) + 실 + 이름표        │ [자정까지 12분]│
│ │ 2장: 오른쪽 가장자리에 '중립 구역' 천 띠          │ ┌── 창문 ──┐ │
│ └──────────────────────────────────────────────┘ └─────────┘ │
│ ═ 기록 띠: 1945 ─ 1953 ─ 1963 ─ 1972 ─ 1984 ─ 1991 ─ 지금 (시계 점) ═ │
│[문서 바구니]  [단서 쪽지][단서 쪽지][단서 쪽지]…    [보고서철 + 도장 2개]│
└──────────────────────────────────────────────────────────────┘
```

- 연도는 일력, 등급은 책상 명패, 장 제목은 인계 일지 표지로 보여 준다. 설정 버튼만 예외로 둔다. 왼쪽 위 작은 종이 탭이고 Esc 키로도 연다. 접근성이 디제시스보다 먼저다.
- 핀에는 국기를 쓰지 않는다. 이름 태그만 단다. 국가 상징을 둘러싼 논란과 AI의 문양 오류를 함께 피한다.

### 3.7 모션 언어: "무게 있는 종이와 기계"
- **종이:** 250~350ms, ease-out, 1~2° 기울기와 그림자. 겹쳐 쌓일 때 살짝 밀린다.
- **실:** 처지는 베지어 곡선이다. 걸릴 때는 스프링(stiffness 300, damping 18 정도)으로 팽팽해지며 '팅' 소리가 난다. 실패하면 2회 흔들린 뒤 늘어져 떨어진다.
- **시계:** 미끄러지지 않고 **뚝, 딱** 끊어 움직인다(한 칸 90ms 이동, 40ms 되튐). 공개 경로에서는 중간값마다 0.6초 멈추고, 그때 넘김 숫자판과 연도가 함께 넘어간다.
- **도장:** 115%에서 100%로 내려찍고, 그림자가 순간 압축되며 '쾅' 소리가 난다.
- **큰 전환은 장 사이에 한 번만** 한다. 버튼 단위 효과는 넣지 않는다(기획서 원칙).
- **reduced-motion:** 모든 이동을 200ms 크로스페이드로 바꾼다. 시계는 숫자만 바뀐다. 입자와 흔들림은 끈다.

## 6. ChatGPT로 일관된 그림을 얻는 방법

### 6.1 작업 순서
1. ChatGPT에 **'자정의 분석실 아트' 프로젝트**를 만들고, 프로젝트 지침에 아래 [화풍 고정] 문구를 붙여 둔다.
2. **스타일 타일**(프롬프트 1)을 만든다. 4장을 뽑아 1장을 고른다. 이 그림이 모든 작업의 기준이다.
3. **기준 방 room-1950s**(프롬프트 2). 스타일 타일을 첨부한다.
4. **스프라이트**: 시계(프롬프트 5)와 코르크 보드. 게임 자리표시 위에 얹어 크기와 느낌을 확인한다.
5. **나머지 방 3장**(프롬프트 3). 매번 스타일 타일과 확정된 room-1950s를 함께 첨부한다.
6. **창밖 7장**(프롬프트 4 틀). 스타일 타일과 이미 확정된 창밖 장면 1장을 첨부한다.
7. **표지 7장, 종이 질감, 타이틀** 순서로 만든다.

### 6.2 규칙
- **첨부 두 장 원칙:** 스타일 타일과 같은 종류의 확정 그림을 늘 함께 첨부한다.
- **한 번에 한 가지만 바꾼다.** "시대만", "빛만"처럼.
- **편집은 두 번까지만 한다.** 같은 그림을 계속 고치면 화질이 떨어지고 화풍이 흐려진다. 두 번 안에 안 되면 기준 그림에서 새로 만든다. 작은 결함은 선택 영역 편집(있다면)으로 고친다.
- **글자를 요구하지 않는다.** 그래도 생긴 가짜 글자는 지우거나 흐리게 한다.
- **투명 PNG가 실패하면** 단색 배경(#00FF00)으로 다시 받아 Photopea(무료 웹 편집기)의 자동 선택으로 지운다.
- **후처리:** Photopea로 자르고 크기를 맞춘 뒤 Squoosh(무료 웹 도구)로 WebP 품질 80으로 바꾼다. 장당 약 150~350KB.
- **좌표 맞추기:** 게임 주소 뒤에 `?layout=1`을 붙이면 보드, 시계, 창 영역 사각형을 끌어서 `layout.json` 값을 복사할 수 있게 개발한다.
- **작업 기록:** 파일명, 날짜, 프롬프트, 고른 번호를 표로 남긴다. AI 고지와 고증 확인에 쓴다.
- **검수 체크:** 사진처럼 보이는가, 사람 손과 얼굴 세부, 가짜 글자, 국기와 로고, 일본·중국풍 건물, 시대에 맞지 않는 물건, 피해 장면.

## 2. 배경 설정 (세계관)

### 2.1 분석실: 문패 없는 4층 끝방

- 서울 어느 낡은 건물 4층 끝에 있는 작은 방. 문에는 '분석실'이라는 글자만 붙어 있다. **실제로 있었던 기관이 아닌 가상의 장소**이며, 타이틀과 크레딧에 "분석실과 분석관은 게임을 위해 만든 가상의 설정입니다"라고 밝힌다.
- 하는 일은 하나다. 세계에서 들어오는 소식(전보, 신문, 라디오, 연설문)을 읽고, 나라 사이의 관계를 보드에 실로 기록하는 것이다.
- **벽시계는 실제 운명의 날 시계를 본뜬 복제품이다.** 1947년 미국 원자 과학자 회보가 시계를 처음 발표하자(사실), 분석실도 벽에 그 시계를 본뜬 시계를 걸고 발표가 날 때마다 직접 바늘을 옮겼다(허구). 기획서 프롤로그의 끝 문구는 사실과 허구가 섞이지 않게 이렇게 바꾼다.
  - "1947년, 미국의 과학자들이 '운명의 날 시계'를 처음 발표했다. 분석실도 벽에 그 시계를 본뜬 시계를 걸었다."
- 프롤로그 동안 시계 자리에는 **못 하나와 벽지가 덜 바랜 동그란 자국**만 있다. 프롤로그가 끝날 때 시계가 걸린다.

### 2.2 분석관: 사람이 아니라 '자리'

- 분석관은 이름도 얼굴도 나오지 않는다. 화면에 보이는 것은 책상과 그 위의 물건뿐이다.
- 80년 동안 그 의자에는 여러 사람이 앉았다. 하지만 플레이어가 맡는 역할은 늘 같은 **'분석관의 자리'**다. 기획서 2.2의 "역할이 바뀌지 않는다"는 원칙은 그대로 지키면서, 81년이 흐르는 시간도 자연스럽게 설명된다.
- **80년 동안 바뀌지 않는 세 물건:** 코르크 보드, 벽시계, 놋쇠 스탠드. 이 셋은 시대가 바뀌어도 **실제로 같은 그림 파일(또는 코드)**로 그린다(4장 레이어 구조). 세계관의 장치가 그대로 제작 방식의 장점이 되는 지점이다. 방은 바뀌어도 세 물건은 한 픽셀도 변하지 않는다.

### 2.5 에필로그의 의미: 지금 이 자리의 분석관은 당신

- 에필로그의 방은 '지금'이다. 노트북과 스마트폰 옆에 1950년대의 놋쇠 스탠드가 그대로 놓여 있다.
- 마지막 연출에서는 방의 불이 모두 꺼지고 남한–북한 황동색 실과 85초를 가리키는 시계만 남는다. 이어서 "이 자리의 다음 분석관은 당신입니다."라는 문구가 뜬다.

### 3.1 화풍: 1950~60년대 잡지 삽화와 실크스크린 인쇄물

**기존 7.2의 '그래픽 노블풍'에서 바꾼다.** 이유는 세 가지다.
1. 게임이 시작하는 시대의 인쇄물 느낌이라 시대감이 있고, 흔한 '웹툰·그래픽 노블' 그림보다 눈에 띈다.
2. **한 장에 5~6가지 색만 쓰면** ChatGPT가 그릴 때마다 생기는 흔들림이 눈에 덜 띄고, 코드로 덧입히는 색 보정과도 잘 맞는다.
3. 누가 봐도 '인쇄된 그림'이라 실제 사진으로 오해될 일이 없다(교육 윤리).

- **질감:** 고운 종이 입자와 아주 옅은 망점(하프톤). 코드로 화면 전체에 덧입히는 입자 층이 그림과 코드 UI의 질감을 하나로 묶는다.
- **원근:** 정면 일점 투시, 수평선이 반듯한 고정 카메라.

- **자정 압력(0~1):** 시계 값에서 계산하는 값 하나로 비네트 강도, 방의 채도, 초침 소리 크기와 빠르기, 시계 둘레의 붉은 빛을 함께 조절한다. 1953년(2분)과 1984년(3분)에는 방이 눈에 띄게 조여 들고, 1991년(17분)에는 방이 숨을 돌린다.

### 3.3 재질

- **놋쇠:** 스탠드, 시계 몸체, 압정. 80년 동안 바뀌지 않는 물건들의 공통 재질이다.
- **코르크:** 보드. 바탕색은 `#B98B5E`이고, 시대가 바뀌어도 색 보정을 받지 않아 실 색이 늘 정확하게 보인다.
- **종이:** 문서. 바탕은 `#E8E1CF`. 시대가 지날수록 종이가 바뀐다(누런 전보 용지 → 갱지 → 감열 팩스 용지 → 흰 A4).
- **나무:** 책상과 창틀. 창틀은 시대에 따라 나무 → 페인트칠한 나무 → 알루미늄 새시 → 흰 PVC로 바뀐다.

### 3.5 시각적 위계: 시계와 실이 주인공

1. **채도 예산:** 방 그림의 채도는 낮게(약 25% 이하) 둔다. 화면에서 채도가 높은 것은 실, 시계 바늘, 형광펜뿐이다.
2. **붉은색 독점:** `#B3261E`는 전쟁 실, 시계 분침, 자정 경고광에만 쓴다. 버튼, 경고창, 장식에는 쓰지 않는다.
3. **층 순서:** 실, 핀, 시계 바늘은 조명 오버레이 **위에** 그린다. 어떤 장에서도 실 색 토큰이 정확한 값으로 보인다.
4. **명도 3단계:** 방(어두움) → 종이와 UI(밝음, 본문 대비 4.5:1 이상) → 실과 시계(가장 선명함). 어두운 장에서도 문서는 늘 스탠드 빛 아래 밝은 종이에 놓인다.
5. **실의 가짜 발광:** 실 아래에 같은 색의 굵고 반투명한 선을 하나 더 깐다(불투명도 18%, 6px). SVG 블러 필터를 쓰지 않아 저사양에서도 가볍다.
6. **코르크 위 회색 실 대비:** 대립 실(`#6E6E6A`)은 코르크 위에서 잘 안 보인다. 모든 실에 1px 짙은 외곽선을 두르고, 이름표는 흰 종이 꼬리표로 붙인다.

### 3.6 실의 '장력' 언어 (색에 기대지 않는 두 번째 신호)

실의 처짐과 떨림으로 관계를 한 번 더 표현한다. 색각 이상 학생도 구분할 수 있고 손맛도 생긴다.

| 관계 | 모양 | 움직임 |
|---|---|---|
| 같은 편 | 두 가닥이 꼬인 실, 곧게 | 고요함 |
| 대립 | 한 가닥, 팽팽하게 곧음, 서리 같은 흰 마디 | 아주 미세한 떨림(웅 소리) |
| 전쟁 | 굵은 실, 팽팽함 | 계속 떨림 |
| 대화 | 살짝 처진 곡선 | 천천히 흔들림 |
| 수교·협력 | 편안하게 처진 곡선 | 정지 |
| 점령 | 회색 점선(기존 유지) | 정지 |
| 균열 | 색은 그대로, 가운데 올이 풀린 모양 | 가끔 툭 끊어질 듯 흔들림 |

`prefers-reduced-motion`에서는 움직임을 모두 끄고 모양만 남긴다.

### 3.7 타이포그래피 (웹 폰트)

| 역할 | 글꼴 | 출처 | 비고 |
|---|---|---|---|
| 로고, 장 제목, 신문 헤드라인 | Nanum Myeongjo ExtraBold | Google Fonts | 활판 인쇄 느낌. **로고와 장 제목은 그림이 아니라 코드로 쓴다**(3.8) |
| UI, 버튼, 설명 | IBM Plex Sans KR | Google Fonts | 기존 유지 |
| 연도, 시계 숫자, 그래프 | IBM Plex Mono | Google Fonts | 숫자 폭이 같아 넘어갈 때 흔들리지 않는다 |
| 전보, 타자 문서(1950~70s) | Nanum Gothic Coding | Google Fonts | 기존 유지 |
| 1980s 팩스·도트 프린터 **머리글만** | Galmuri11 | npm `galmuri`(OFL, 직접 호스팅) | 본문에는 쓰지 않는다(가독성) |
| 인수인계 메모, 손글씨 | Gaegu | Google Fonts | 22px 이상, 세 줄 이하 |

- 본문은 20px(최소 18px), 줄 간격 1.7, 한 줄 34자 이내.
- 형광펜 색은 `#F3E37A`(곱하기 혼합)로 실 색과 겹치지 않게 한다.

### 3.8 기존 7장에서 바꾸는 점과 이유

1. **방 그림에서 코르크 보드, 시계, 창틀을 뺀다.** ChatGPT는 같은 위치를 지키지 못한다. 세 물건을 코드와 공용 스프라이트로 그리면 `layout.json` 좌표 하나로 네 시대 모두 정확히 겹친다.
2. **그림 속 한글 제목은 쓰지 않는다.** 오타 위험이 있고, 수정이 어렵고, 크기를 바꾸면 흐려진다. 로고와 장 제목은 코드 글꼴로 쓰고 그림은 글자 없이 만든다.
3. **기준 방은 1970년대부터 만든다.** 버티컬 슬라이스가 3장이기 때문이다.
4. **시대 색 4개를 장별 색 스크립트 7개로 넓힌다.** 같은 방을 쓰는 장끼리도 감정 곡선이 달라야 한다.
5. **문서 종이를 3종에서 5종(세로형)으로 늘린다.** 문서 형식 5개에 맞추고, 문서는 세로가 자연스럽다.
6. **도전 과제 아이콘은 코드로 만든 도장 모양을 쓴다.** 그림 8장을 같은 화풍으로 맞추는 비용이 크다.

### 3.9 모션 언어: 무게 있는 종이, 팽팽한 실, 기계식 시계

| 대상 | 규칙 |
|---|---|
| 종이 | 240ms, `cubic-bezier(.2,.8,.2,1)`. 놓일 때 ±1.5° 기울어졌다가 자리 잡고, 그림자가 짙어진다. |
| 형광펜 | 왼쪽에서 오른쪽으로 250ms에 걸쳐 그어진다(SVG 마스크). |
| 실 | 스프링(stiffness 300, damping 12). 성공하면 '팅' 하고 0.6초 동안 떨리고, 실패하면 좌우로 흔들린 뒤 풀린다. |
| 시계 바늘 | **매끄럽게 돌지 않는다.** 한 칸씩 '딱' 끊어 움직이고 살짝 넘쳤다 돌아온다. 공개 경로에서는 값마다 0.9초 멈추고 연도와 캡션이 뜬다. |
| UI | 120ms 투명도 변화와 1px 이동만. 버튼에는 다른 효과를 넣지 않는다. |
| 시대 전환 | 램프 컷 약 1.6초. 화려함은 이 순간에만 몰아서 쓴다. |
| 동작 줄이기 설정 | 모든 움직임을 150ms 페이드로 바꾸고 입자와 떨림을 끈다. |

## 6. ChatGPT 작업 순서, 규칙, 대표 프롬프트

### 6.1 작업 순서

1. **ChatGPT 프로젝트 만들기:** "자정의 분석실 아트" 프로젝트를 만들고, 프로젝트 지침에 아래 [화풍]과 [금지] 블록을 붙여 넣는다.
2. **키 아트(스타일 기준):** 프롬프트 1로 4~6번 생성해 가장 마음에 드는 1장을 고른다. 이후 **모든 요청에 이 그림을 첨부**한다.
3. **기준 방(1970s):** 프롬프트 2. 키 아트를 첨부한다.
4. **나머지 방:** 프롬프트 3. 기준 방과 키 아트를 첨부해 "편집"으로 요청한다.
5. **공용 스프라이트와 질감:** 시계 몸체(프롬프트 5), 스탠드, 코르크, 나무.
6. **종이 5종:** 6.4 변형 표.
7. **창밖 7장:** 그림마다 새 대화를 열고 키 아트와 해당 시대 방을 첨부한다(색감을 맞추기 위해).
8. **표지 7장:** **한 대화 안에서 이어서** 만든다(연작 일관성). 첫 표지를 고른 뒤에는 그 표지도 함께 첨부한다.

### 6.2 규칙

- 한 번에 한 장만 만들고, 한 번의 수정 요청에서는 한 가지만 바꾼다.
- 수정을 세 번 해도 흔들리면 **새 대화를 열고 첨부부터 다시** 한다.
- 다음 말은 쓰지 않는다: "사진", "실사", "시네마틱", "4K", "고화질 렌더", "극사실".
- [화풍]과 [금지] 블록은 한 글자도 바꾸지 않고 매번 붙인다.
- 받은 그림은 바로 파일명대로 저장하고 `_v1`, `_v2`처럼 번호를 붙인다. 고른 그림만 `public/assets/`에 넣는다. PNG로 넣으면 빌드할 때 WebP로 자동 변환되게 설정한다(Claude Code 작업).
- **검수 체크리스트:** 글자·숫자·로고가 없는가 / 사진처럼 보이지 않는가 / 얼굴 세부와 손 클로즈업이 없는가 / 일본·중국풍 건물이 없는가 / 상표·국기 문양이 없는가 / 고증 항목을 교사가 확인했는가

## 0. 요약: "스팀 게임 느낌"은 어디서 나오나

비싸 보이는 인디 게임은 그림이 많아서가 아니라 아래 다섯 가지가 일관되기 때문에 비싸 보인다. 이 제안서는 다섯 가지를 교사 한 명, ChatGPT, 저사양 크롬북이라는 조건 안에서 확보하는 방법이다.

1. **하나의 화풍**: 기준 그림 한 장에서 모든 그림을 파생시키고, 후처리 색 보정으로 차이를 줄인다.
2. **빛**: 극적인 명암은 그림이 아니라 코드로 넣는다. 방의 밝기가 시계와 연동된다.
3. **손맛**: 모든 조작에 소리와 무게감 있는 움직임이 붙는다(실 튕김, 도장, 종이).
4. **메타 층**: 살아 있는 타이틀, 장 표지, 도전 과제 알림, 장 결과 화면, 크레딧.
5. **여백**: 화면에서 화려한 것은 시계와 실 두 가지뿐이다.

### 기획서 7장에서 바꾸는 것 (이유)

| # | 기존 | 제안 | 이유 |
|---|---|---|---|
| 1 | 방 전체를 그림 한 장으로, 보드·시계·창 자리는 비워 둠 | **레이어 분리**: 시대별 벽 그림 + 공용 스프라이트(보드, 시계 테두리, 책상, 램프) + 시대 소품 스프라이트 | ChatGPT는 같은 픽셀 위치를 보장하지 못하고 "비운 영역"도 잘 못 만든다. 시대마다 보드 위치가 어긋나면 SVG 실 좌표가 깨진다. 공용 스프라이트는 한 장을 80년 내내 쓰므로 어긋날 일이 없다. |
| 2 | 챕터 표지·로고의 한글 제목을 그림에 넣음 | **모든 글자는 코드로** | 오탈자 위험이 있고, 제목을 바꿀 때 재생성이 필요하며, 도장 찍기 같은 연출을 할 수 없다. |

## 2. 배경 설정 (세계관)

### 2.1 분석실

- **가상의 신문사 「새벽신보」(가칭) 꼭대기 층의 외신 분석실.** 외신 전보와 라디오 방송을 받아 읽고, 나라 사이의 관계를 정리해 1면 해설 기사를 쓰는 작은 방이다.
  - `TODO(교사 확인)` 가칭이 실재했거나 실재하는 매체 이름과 겹치지 않는지 검색한다.
  - 신문사 설정이 부담스러우면 기관 이름을 빼고 '분석실'만 남겨도 나머지 설계는 그대로 작동한다.
  - 국내 언론사(언론 통폐합 등)의 역사는 다루지 않는다. 화면에 국내 정치 문서를 넣지 않는다.
- 이름 '자정'과 '새벽'이 짝을 이룬다. 시계는 자정을 향하고, 분석실은 새벽을 기다린다.
- 타이틀 아래와 크레딧에 고지: **"분석실, 신문사, 분석관은 가상의 설정입니다. 사건, 연도, 시계 값은 실제 기록을 따릅니다."**

### 2.2 분석관은 누구인가

- 플레이어는 **'이번 분석관'**이다. 이름도 얼굴도 손도 나오지 않는다. 플레이어는 의자에 앉은 시선 그 자체다.
- 분석관은 시대마다 바뀐다. 1945년의 첫 분석관이 은퇴하면 다음 사람이 그 자리에 앉는다. 화면에는 '제1대 분석관', '제4대 분석관'처럼 번호로만 표시한다.
- 손과 얼굴을 그리지 않으므로 AI 이미지의 약점(손)을 피하고, 학생 누구든 자기를 대입할 수 있다.

### 2.3 80년이 같은 방에서 자연스러운 이유: 변하지 않는 세 가지

| 변하지 않는 것 | 설정 | 효과 |
|---|---|---|
| **책상** | 1945년부터 같은 나무 책상. 장마다 컵 자국과 긁힌 자국이 하나씩 늘어난다(코드 데칼). | 공용 스프라이트 한 장으로 80년. Unpacking처럼 흔적이 세월을 말한다. |
| **벽시계** | 분석관이 원자 과학자 회보의 발표를 듣고 직접 바늘을 옮겨 거는 '분석실의 시계'. 프롤로그(1945~1947)에는 시계 자리에 못 하나와 빛바랜 네모 자국만 있다. 1947년 "과학자들이 시계를 걸었다"와 함께 시계가 그 못에 걸린다. | "시계는 측정값이 아니라 과학자 단체의 평가"라는 점이 세계관 안에서 자연스럽다. |
| **코르크 보드** | 핀은 80년 동안 같은 자리에 꽂혀 있고, 실만 다시 걸린다. | 보드 좌표가 고정되므로 기술적으로도 안정적이다. |

바뀌는 것: 벽(페인트, 조명 기구), 창틀(나무에서 알루미늄 새시로), 책상 위 기계(라디오, 텔레비전, 팩스, 노트북), 문서의 글꼴.

### 2.4 장과 장을 잇는 장치 (학습 장치 겸용)

1. **인계 메모 (복습)**: 장이 시작되면 이전 분석관이 남긴 손글씨 메모가 책상에 놓인다. 지난 장의 핵심 2~3줄 중 한 칸이 비어 있다. 예: "중국–소련 실은 아직 [ ]이었다. 그런데 실이 해어지기 시작했다." 학생이 보드의 실 이름표를 눌러 채운다. 점수와 무관하고 건너뛸 수 있다. 30초 분량. (챕터 JSON에 선택 필드 `handover` 추가, 문구는 데이터 파일에)
2. **시계 판의 연필 눈금 (인과의 흔적)**: 시계 값이 공개될 때마다 분석관이 시계 판 가장자리에 연필로 짧은 눈금과 연도를 적는다. 시계 하나만 봐도 1947년 이후의 흐름이 보인다. 전체 그래프는 서랍형 기록 보관소에 있다.
3. **실의 이력표 (관계 변화)**: 실 이름표를 뒤집으면 그 실의 이력이 나온다. 예: 미국–중국 "1950 전쟁 → 1953 대립 → 1971 대화 → 1979 수교·협력". "냉전은 관계의 변화"라는 학습 목표 2를 직접 보여 준다.
4. **표지의 질문 (선행 조직자)**: 장 표지에 그 장의 질문 하나를 띄운다. 예: 3장 "같은 편이던 두 나라는 왜 국경에서 총을 겨눴을까?"
5. **방의 밝기 = 시계**: 2.6 참고.

### 2.5 에필로그의 의미: 인계는 끝나지 않는다

- 방은 '지금'이다. 노트북과 스마트폰이 있지만 책상과 시계와 보드는 그대로다.
- 보드는 5장 상태로 고정되고 남한–북한 실만 천천히 맥박친다.
- 85초가 공개되면 방의 빛이 게임 전체에서 가장 어두워지고, 노트북 화면 빛과 황동색 실만 남는다.
- 마지막 장면에서 학생은 **'다음 분석관에게 남길 메모'** 한 줄을 쓸 수 있다(선택, 브라우저에만 저장). 정답은 없고 게임은 어떤 입장도 제시하지 않는다(기획서 11.2). 크레딧에 학생 자신의 메모와 그동안 쓴 헤드라인이 신문 더미로 쌓인다.
- 메시지: 이 방에서는 80년 동안 실이 계속 다시 걸렸다. 남은 실을 읽는 일은 이제 지금의 분석관, 곧 학생의 몫이다.

### 2.6 방의 밝기 = 시계까지의 거리

- 색조(hue)는 시대와 장이 정하고, 밝기는 시계가 정한다.
- `night = clamp((17 − 남은 분) / 15, 0, 1)`
  - 17분(1991) → 0: 맑은 아침
  - 12분 → 0.33: 늦은 오후
  - 7분 → 0.67: 해 질 녘
  - 2분(1953) → 1: 깊은 밤
  - 85초(2026) → 1에 '기록' 플래그(가장자리 붉은 기운과 채도 감소)
- 시계 공개 연출에서 바늘이 움직이는 동안 방의 빛도 함께 바뀐다. 쿠바 위기 뒤 시계가 '멀어지는' 반전에서는 방이 밝아진다. 학생은 결과를 눈으로 먼저 느낀다.
- 프롤로그(시계가 걸리기 전)는 서사에 따라 정한다: 해방의 늦여름 아침.
- 튜토리얼에서 한 번만 안내한다: "이 방은 시계와 함께 어두워지고 밝아진다."

## 3. 비주얼 아이덴티티

### 3.1 화풍

- **선**: 가늘고 살짝 떨리는 갈색-먹색 잉크선. 검정 외곽선은 쓰지 않는다(그림이 '만화'처럼 가벼워짐).
- **면**: 구아슈(불투명 수채) 느낌의 넓은 색면. 붓 자국이 은은하게 보인다. 그라데이션은 최소로.
- **질감**: 모든 그림 위에 코드가 같은 종이 결 레이어를 깐다. 생성 이미지마다 다른 질감이 이 레이어로 통일된다.
- **명도**: 그림은 '중간 밝기, 낮은 채도'로 받는다. 극적인 명암은 코드 조명이 넣는다. 그림에 어둠을 깊게 구워 넣으면 나중에 밝게 만들 수 없다.
- **조명 방향 규칙(모든 그림 공통)**: 주광은 왼쪽 앞 탁상 램프(따뜻한 빛), 보조광은 오른쪽 창. 그림자는 오른쪽 아래로 짧고 부드럽게.
- **사실성 금지**: 사진 질감, 3D 렌더링 느낌, 얼굴 이목구비 묘사를 금지한다.

### 3.2 시각적 위계: 주인공은 시계와 실

| 층 | 요소 | 명도·채도 규칙 |
|---|---|---|
| 1층 (주인공) | 시계 판, 실 | 시계 판이 화면에서 가장 밝다(크림 #F3ECDD, 자체 조명). 실은 화면에서 가장 채도가 높은 요소. 다른 어떤 요소도 실보다 채도가 높으면 안 된다. |
| 2층 | 열린 문서, 나라 핀 이름표, 단서 칩 | 종이색, 잉크색. 강조는 형광펜 노랑 한 가지(#F2D35B, 문서 안에서만). |
| 3층 | 벽, 책상, 소품, 창밖 | 빌드 스크립트에서 채도 85%, 명도 −5%로 일괄 보정. 비네트로 화면 가장자리를 어둡게. |

- 나라 핀은 국기 없이 **놋쇠 압정 + 타자 이름표**. 핀에 색을 쓰지 않아야 실이 돋보인다.
- 붉은색은 한 번에 하나만: 시계 분침, 전쟁 실, 제출 가능할 때의 도장 인주.
- UI 크롬은 얇은 놋쇠선(#9C7A3C, 1px)과 종이색만. 채도 있는 버튼은 없다.

| 역할 | 글꼴 | 규칙 |
|---|---|---|

| 인계 메모, 연필 눈금 | Gaegu (700) | 손글씨는 22px 이상, 3줄 이하에서만 |

- 1980년대 '도트 프린터' 느낌은 본문 글꼴을 바꾸지 않고, 머리글 줄에 가로 줄무늬 배경과 약간의 번짐 그림자로 낸다. 도트 글꼴 본문은 중2 학생에게 읽기 어렵다.
- **가독성 함정**: 학교 크롬북의 흔한 해상도 1366×768에서는 3:2 무대가 0.75배로 줄어든다. 무대 안에서 18px로 쓴 글자는 실제로 13.5px가 된다.
  - 해결: **문서 읽기 창, 보고서, 인계 메모는 축소되는 무대 밖의 오버레이**로 띄우고 실제 화면 픽셀 기준으로 본문 18px 이상을 보장한다.
  - 무대 안 글자(핀 이름표, 실 이름표)는 무대 단위 24px 이상(0.75배일 때 18px).

### 3.6 모션 언어: "모든 움직임에는 무게가 있다"

| 재질 | 움직임 | 값 (Motion) |
|---|---|---|
| 종이 | 가볍게 미끄러지고 1~2도 기울었다가 놓임 | 0.28s, easeOut, 회전 ±1.5° 정착 |
| 실 | 걸면 튕기며 2~3번 출렁 | spring stiffness 300, damping 9 |
| 놋쇠·시계 | 무겁고 끊어지는 걸음. 1분마다 '탁', 4% 넘쳤다가 돌아옴 | 한 걸음 0.12s + 오버슛 |
| 빛 | 느리게 번짐 | 1.5~4s, easeInOut |
| 장면 전환 | 가장 느림 | 4~6s, 언제든 건너뛰기 가능 |

- 금지: 버튼이 통통 튀는 효과, 의미 없는 확대 팝업, 화면 흔들림(쿠바 위기 직후 1회만 예외).
- `prefers-reduced-motion`: 모든 움직임을 0.2초 이하 투명도 전환으로 바꾼다. 시계 바늘은 한 번에 이동, 시차(패럴랙스)와 입자는 끈다.

### 5.1 시계 상세 (주인공)

- 판: SVG. 크림색 판, 12개 눈금, 11시 45분~12시 구간에 옅은 붉은 띠. 원자 과학자 회보의 상징 디자인(4분의 1 시계판)은 따라 하지 않고 일반 벽시계로 만든다.
- 바늘: 분침 #B3261E, 시침은 짙은 놋쇠. 바늘 그림자는 같은 경로를 3px 비껴 투명도 25%로(필터 없음).
- 유리 반사: 흰색 선형 그라데이션 띠 하나, 마우스 시차에 따라 살짝 이동.
- 자정에 가까울수록: 판 뒤 붉은 방사형 빛의 투명도 상승, 초침 소리의 빠르기 1.0→1.6, 시계 크기 1.0→1.08.
- 에필로그 85초: 분 단위로는 차이가 안 보이므로 시계 앞에 원형 확대 렌즈가 내려와 초 단위 눈금을 보여 준다.
- 시계를 누르면 "이 시계는 과학자 단체의 평가이며 실제 측정값이 아니다" 설명 카드(기획서 5.3).

### 5.2 성능 예산 (저사양 크롬북 기준)

| 항목 | 예산 |
|---|---|
| 전체 화면 그림 1장 | WebP 300KB 이하 |
| 스프라이트 1장 | WebP 120KB 이하 |
| 장 하나를 시작할 때 내려받는 양 | 1.5MB 이하(다음 장은 현재 장 후반에 미리 받기) |
| 게임 전체 그림 | 10MB 이하 |
| 동시에 디코딩된 큰 비트맵 | 8장 이하(1장 약 6MB 메모리) |
| 동시에 화면에 있는 이미지 레이어 | 10개 이하 + SVG 1개 + Canvas 1개 |
| 애니메이션 속성 | `transform`, `opacity`만 |
| 금지 | 큰 레이어에 CSS `filter: blur`, 움직이는 요소에 SVG `feGaussianBlur`/`feTurbulence`, 전체 화면 `mix-blend-mode` 애니메이션 |
| 전환 직전 | `await img.decode()`로 디코딩을 끝낸 뒤 시작 |
| 저사양 모드 | 시작 3초 동안 프레임을 재서 40fps 미만이면 자동으로 '가벼운 효과'(입자, 시차, 그레인 끔). 설정에서 직접 켜고 끌 수 있음 |

### 5.3 자산 빌드 스크립트 (`npm run assets`, sharp 사용)

1. `art-src/`의 원본 PNG를 읽어 투명 여백 자르기, `layout.json` 크기로 줄이기, WebP 변환.
2. 3층 그림에 일괄 색 보정(채도 85%, 명도 −5%).
3. 창틀의 유리 영역(`window.pane`)은 원본과 관계없이 투명하게 구멍을 뚫는다.
4. **가짜 투명 검사**: '투명'이어야 하는 그림의 네 모서리 알파가 0이 아니면 경고. ChatGPT가 투명 배경 대신 회색·흰색 바둑판 무늬를 그려 넣는 경우를 잡는다.
5. 용량 예산을 넘으면 경고, 문서 집중용 흐린 벽 그림 생성, `assets.manifest.json` 출력.

## 6. ChatGPT로 일관된 결과를 얻는 방법

### 6.1 작업 순서

1. **준비**: ChatGPT '프로젝트'를 하나 만들고(이름: 자정의 분석실 아트), 프로젝트 지침에 아래 '스타일 바이블'을 붙여 둔다.
2. **기준 그림(프롬프트 1)**: 3~4번 생성해 하나를 고른다. 마음에 들 때까지 다음으로 넘어가지 않는다. 이 그림이 모든 그림의 정답지다. 1~2시간을 써도 아깝지 않다.
3. **공용 스프라이트**: '공용' 대화 하나에서 보드 → 시계 테두리 → 책상 → 램프 → 문서 꽂이 → 도장 → 창틀 순서로. 매번 기준 그림을 첨부한다(프롬프트 3 형식).
4. **벽 플레이트**: room-1970s 먼저, 그다음 기준 그림과 room-1970s를 함께 첨부해 나머지 세 시대(프롬프트 2).
5. **시대 소품**: 1970년대 → 1950년대 → 1980년대 → 지금.
6. **창밖 장면**: '창밖' 대화를 따로 연다. window-ch3을 먼저 완성하고, 이후에는 기준 그림과 window-ch3을 함께 첨부.
7. **표지**: '표지' 대화를 따로 연다. cover-ch3을 연작의 기준으로 삼는다.
8. **질감, 배지**.

그림마다: 생성 → 6.4 검수 → 작은 문제는 ChatGPT 편집 화면에서 영역을 선택해 고치기 → 화풍이 틀어졌으면 참고 그림 2장을 첨부해 다시 생성 → `art-src/이름_v03.png`로 저장 → `npm run assets` → `?layout=1`에서 위치 확인.

### 6.2 규칙

- 스타일 바이블은 **한 글자도 바꾸지 않고** 매번 붙인다.
- 한 요청에 한 그림. 여러 개를 한 장에 격자로 그리게 하지 않는다(개수와 정렬이 틀린다).
- 위치와 크기는 그림에 맡기지 않는다. 위치는 `layout.json`이 정한다.
- 그림에 글자를 넣지 않는다. 간판, 신문, 화면 속 글자도 "글자 없는 색면"으로.
- 사람은 작게, 뒷모습이나 옆 실루엣으로. 얼굴 이목구비는 그리지 않는다.
- 투명 그림은 "배경 완전 투명, 바닥 그림자 없음"을 쓰고, 받은 뒤 반드시 확인한다.
- 생성이 이상하게 흔들리면 그 대화를 버리고 새 대화에서 참고 그림을 첨부해 다시 시작한다(대화가 길어지면 화풍이 흐려진다).
- 원본과 버전을 모두 보관한다. 고른 그림만 `art-src/`에 둔다.

### 6.5 자주 쓰는 수정 요청 (그대로 붙여 쓰기)

### 6.6 검수 체크리스트 (그림마다)

- [ ] 화풍: 잉크선이 보이고, 구아슈 면이며, 사진이나 3D 렌더링처럼 보이지 않는다.
- [ ] 기준 그림 옆에 나란히 놓았을 때 한 게임의 그림으로 보인다(선 굵기, 채도, 밝기).
- [ ] 빛이 왼쪽 앞에서 오고 그림자는 오른쪽 아래를 향한다.
- [ ] 글자, 숫자, 로고, 국기, 상표, 워터마크가 없다(확대해서 확인).
- [ ] 사람이 있으면 작고, 이목구비가 없고, 손이 어색하지 않다.
- [ ] 실존 인물로 보이는 사람이 없다.
- [ ] 비극은 간접 묘사다(부상, 시신, 폭발, 추락 장면 없음).
- [ ] 한국 장면에 일본식·중국식 건물이나 장식이 없다.
- [ ] 시대 고증(옷, 건물, 탈것, 기계)을 교사가 확인했다. 의심스러우면 `TODO(교사 확인)`을 `art-src/README`에 적는다.
- [ ] 투명 그림: 바둑판 무늬가 아니라 실제 투명이고, 가장자리에 흰 테두리(헤일로)가 없다(빌드 스크립트 경고 확인).
- [ ] 파일명이 4.3 표와 같고 `art-src/`에 버전과 함께 저장했다.
- [ ] `?layout=1`에서 위치를 맞췄고 실, 시계, 이름표를 가리지 않는다.

### 6.7 제작 시간 추정

한 장에 생성, 검수, 수정까지 10~25분. M2 최소 세트 14장은 약 4~5시간, 전체 46장은 약 12~16시간. 주말 두세 번에 나눠 하는 분량이다. 게임 개발은 자리표시 그림으로 먼저 진행하므로 그림 작업과 병행할 수 있다.
